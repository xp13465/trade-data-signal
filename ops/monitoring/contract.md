# Operations monitoring v1 wire contract

Task-specific user authorization: Codex implements in this isolated branch; Claude reviews, merges and deploys. This does not change the normal reviewer role.

## Snapshot
POST /api/ops/ingest, Authorization: Bearer OPS_INGEST_TOKEN (never viewer privilege). JSON <=256 KiB, schema_version=1, snapshot_id UUID, collector_id [a-z0-9_-]{1,48}, collected_at UTC ISO string, code_ref full40 SHA or unknown, duration_ms integer, checks <=250. Each check: id stable [a-zA-Z0-9:._-]{1,120}, name<=160, category in service/timer/data/publication/backup/resource/monitor, status in ok/warning/critical/unknown, observed_at ISO, summary<=400, evidence object with ONLY scalar safe values <=20 keys <=400chars each; no paths/tokens/log bodies/argv/env. Top-level coverage object is {counts:{safe_name:nonnegative_integer,...},limitations:[safe_text,...]} (<=30 counts and <=20 limitation strings); collector errors become explicit unknown checks. Optional baseline {code_ref, generated_at, records:[...] } is NOT accepted at ingest; baseline is server-bundled versioned data.

## API
All /api/ops/* no-store and no CORS. GET /api/ops/state returns {schema_version:1, server_time, latest: snapshot|null, collector_status: unknown|fresh|stale, counts, events:[...]}; GET /api/ops/history?limit=... returns {runs:[{snapshot_id,collected_at,received_at,counts,duration_ms}]}; GET /api/ops/events?limit=... returns {events:[...]}; GET /api/ops/knowledge returns {schema_version, baseline_code_ref, observed_at, records:[all inventories records]}; GET /api/ops/incidents returns {incidents:[baseline incident records with independent overrides], revisions:[...]}. GETs require explicit admin session (getSessionUser plus shared getAdminUsers: union of ADMIN_USERS and ADMIN_USERS_ADDITIONS, matching exact provider:providerUid) OR X-Ops-Admin-Token=OPS_ADMIN_TOKEN (bootstrap, separate from ingest). Ordinary logged-in user forbidden. Missing bindings fails503. Optional GET /api/ops/export = private combined JSON backup.

POST /api/ops/incidents/:encoded_id updates {expected_revision, workflow_status (unknown/open/investigating/repairing/in_progress/blocked/verification/observing/closed/accepted_risk/not_replayable), root_cause_state, remediation_state, deployment_state, verification_state, observation_status, note, evidence_url}. Auth admin; cookie request must same-origin, require application/json and X-Ops-Intent: update. Optimistic revision conflict409; append audit revision; never overwrite baseline evidence, no automatic human issue closure. Closure requires evidence and explicit verification/observation, no automatic root-cause claims.

## Persistence and watchdog
Dedicated OPS_DB D1 (never public R2, never SUBSCRIBE_KV/FUND_SCORE_DB). Schema migration in ops/monitoring/migrations. Ingest atomic, duplicate snapshot same content idempotent, conflicting ID409; reject >2min future or >30min old; older accepted fresh input cannot replace newer latest or regress event current state. Store bounded full recent snapshot (24h) + summary history30d; retain events/revisions90d; retention occurs scheduled. Watchdog scheduled every15min independently of collector: latest age>1800s stale, missing latest unknown. Persist event only state transitions, initial ok silent, recovery once; never page on status unknown from stale baseline. Optional OPS_ALERT_WEBHOOK Feishu v2 HTTPS approved host only + OPS_ALERT_ENABLED=true. Default OPS_ALERT_SCOPE=watchdog only pages collector freshness transitions; business state events remain recorded and are suppressed because the existing alert chain owns business paging. Explicit all scope requires Claude to review ownership/deduplication first; invalid scope cannot send. Outbox persisted retries bounded, delivery status visible; tests fake transport only, no actual sending. Repeated failure not a new event. Any sender can at-least-once duplicate after ambiguous network timeout: document this, no exactly-once claims. Collector push every15min systemd timer.

## Frontend
/admin/ops.html (+ ops.js/ops.css), public empty shell no private data embedded. Session admin default; bootstrap token in memory only explicit form. Fetch state/history/events/knowledge/incidents with no-store, AbortController, no overlapping polls, clear private DOM on auth expiry/logout. Tabs overview/services+timers/data+publication/architecture/incidents/history. Search/filter/details, evidence timestamps, fresh/stale/unknown distinguished, architecture edges navigable from versioned knowledge. Compact mobile controls, no business page CSS modifications. Dashboard can edit issue overrides with optimistic revision and export private snapshot. If missing binding/data show setup/unknown, never default green.

## Deployment
Parent integrates worker/headers.js import + routes + scheduled, local-only Wrangler config with all simulated bindings; no stock config dev (production SUBSCRIBE_KV remote:true). Dedicated D1 creation, secret provisioning, production config merge/timer enable are Claude deployment steps. No new public cloud ports. Local implementation/tests must be complete before handoff.
