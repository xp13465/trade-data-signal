### 2.4 推荐:选项A(去 D1a 保留 C1 主体)

**推荐理由**(按重要性排序):

1. **精准去除过拟合元凶,保留有效部分**:诊断报告(§3.3-3.4)锁定 `dist_from_low60_d1a` CV=146% 为过拟合元凶(各段 0.015/0.25 乱跳),D1a 的另 2 阈值(atr_pct_d1a_low/dev_ma60_d1a)CV<18% 稳定但依附于不稳定的 dist_from_low60_d1a。选项A 精准删 D1a 整个子句,保留 C1 主体(atr_pct_high CV=17.9% / dist_from_high_th CV=28.6%,中等稳定且 L1167-1169 实测全面改善)。符合"尽可能完整正确"准则--不是偷懒去除整个 sh 专属,而是精准去除过拟合部分保留有效部分。

2. **保留 sh 大盘趋势性专属价值**:L1162-1170 注释明确 sh 大盘趋势性强,C1 的 `dist_from_high>=15%`(距 250 日高点跌 15%=低位假突破)是针对 sh 特性调出的有效规则。L1167-1169 实测单 C1 vs sh 豁免基线:mdd -3.72%→-3.01%(降 0.71pp)、peak 10.38%→7.35%(降 3.02pp/29%)、ret20 +5.27%→+6.29%(升 1.02pp 不损反升)、bot_acc 66.04%→69.12%(升 3.08pp),全面改善。选项B 把这部分有效过滤也去掉,不符合"收益要稳"目标。

3. **与 h5 R2 协同互补**:C1 是"sh 大盘趋势性专属"(距高点远=低位假突破,针对 sh 趋势性强的特性),h5 R2 是"通用顶部信号"(高波动+均线偏离+量价背离,7/7 稳健)。两者过滤维度不同(C1 位置维度 / h5 R2 量价+波动维度),互补不重叠。选项B 完全统一用 h5 R2 会失去 C1 的位置维度过滤。

4. **改动最小,可回退性最高**:选项A 删 2 行+改 1 行,git revert 即可恢复;选项B 删 13 行+替换 1 行,恢复整个 if 分支较复杂。符合"可回退性"优先准则。

5. **WF 预估达标即可**:选项A 的 WFE 预估 >0.6(可接受或稳健),虽不如选项B 的 ~1.04 稳健,但已消除过拟合(从 0.336 提升)。若实施时重跑 WF 确认 WFE>0.6,则选项A 的样本内收益保留(mdd -3.01% vs 选项B -3.72%)+ 样本外稳定性达标,综合优于选项B。

6. **风险可控**:选项A 的 mdd 退化 +0.36pp、peak 退化 +1.77pp,均在可接受范围(远小于选项B 的 +1.07pp/+4.80pp);ret20 反升 +1.98pp(D1a 误杀好信号恢复),是正向收益。选项B 的 mdd/peak 大幅退化可能触发用户"降回撤"诉求底线。

**不推荐选项B 的原因**:虽 WF 稳定性最好(~1.04),但样本内 mdd -3.72%/peak 10.38% 退化到"sh 豁免"状态,失去 C1 有效过滤,且 L1162-1170 注释已明确 sh 用方案 B(dist_from_low60>30%)误滤。选项B 的"完全通用化"是长期方向(报告 §3.6 建议4),但需先验证 h5 R2 单独对 sh 的 trade_sim 收益可接受,短期选项A 更稳妥。
