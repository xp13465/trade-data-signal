## 五、动工前预览结论

### 5.1 预期效果

1. **过拟合挤掉多少**:40 个场景退出三档 chip 候选(占当前 48 个进 chip 候选的 83%),覆盖 7 个过拟合 / 小样本品种。chip 推荐将聚焦稳健品种(上证综指 8 个场景全保留 + 其他稳健品种)。
2. **稳健信号保留**:7 类信号全部保留(种类不变,只降级不删)。情况 A 稳健信号(CGB_BAND / buy_special 基础 / buy_backup / D1 sh/hs300 / sell_stop_loss sh/hs300 / B1 辅买)全部不动,继续参与 chip 推荐。
3. **整体效益变化**:
   - 代码层仅 csi_div 4.5->3.5 一行改动,该品种追买+追止损卖场景收益 -15~25%(78.43% -> 59~67%),但消除 per-index 过拟合,wf 夏普预计改善。
   - 其余 10 个信号 - 品种对仅前端标注(代码不动,触发数与收益不变),用户仍能在 trade_sim 页面查看,只是不进 chip 推荐。
4. **实盘复现概率提升**:剔除 WFE<0.5 的过拟合品种 chip 推荐,实盘复现概率从"全样本参数过拟合到历史"提升到"基于测试段验证的稳健信号"。csi_div 4.5->3.5 消除 per-index 过拟合,实盘不再依赖历史拟合的 4.5 倍。

### 5.2 不确定性与风险

1. **csi_div 4.5->3.5 收益降 15~25% 是预估值**(依据 `signals.py` L1043 注释"4.5 降 24% 信号数"反推),实际需跑回测确认。若实际降幅超 30% 或 wf 夏普未改善,可回滚保留 4.5。
2. **情况 C 疑似信号(hands v5 / sh C1\|D1a / h5 R2)暂不动**,补跑 WF 工作量大(需复刻 8+8 维度计算 / 5 阈值单指数 WF / 6 阈值全指数 WF)。若补跑后 WFE<0.5,再纳入情况 B 降级。
3. **小样本品种(kc50 等)前端标注后用户可能误读为"信号失效"**,需文案明确"样本不足仅供参考,非信号本身问题"。
4. **40 个场景退出 chip 后,部分品种(科创 50 / 中证红利 / 申万汽车)可能无 chip 推荐**,需兜底文案"该品种暂无达标推荐,详见 trade_sim 完整回测"。

### 5.3 动工建议顺序(用户定)

1. **第一步(代码层最小改动)**:csi_div sell_stop_loss 4.5->3.5(`signals.py` L726, L1044 删 csi_div 项)+ 跑 trade_sim 对比 + 上线。预期 1 个品种 1 个场景收益变化,影响面最小。
2. **第二步(前端标注)**:`app.js` 加"过拟合 / 样本不足"标注 chip,40 个场景退出三档 chip 候选。无代码层信号改动,纯展示层。
3. **第三步(补跑 WF)**:对 hands v5 / sh C1\|D1a / h5 R2 补跑完整 WF,确认 WFE 后再决定是否纳入情况 B 降级。工作量最大,可独立排期。
