## 正常周期的通过条件

| 项目 | 应观察的行为 | 不足以关闭问题的现象 |
|---|---|---|
| R2 共享产物 | 本轮真实生成的共享文件由普通主上传消费；同 key 发布互斥；并发补跑携带对应运行上下文；失败/未消费请求有可追踪结果 | verify 补传成功、告警暂时消失、单次上传 exit 0 |
| NAV | 零行完成项能按预算进入后续请求；正常空保持非故障、留待后续；已有行的 done 和 manager 合法空均保留 | 新进度有 retry 字段、官方已有净值、只验证新加代码而没检查原失败对象 |
| 备份诊断 | 真失败仍 exit 1，正文能点名库、表、两端数量或不可读原因，健康库继续检查 | 校验器异常后仅有空通用正文、只看到周频 SKIP |
| 冻结缺失 | 下一次真实 guard 产生完整、唯一、不覆盖的同轮 filtered 集合；拒补冻、accepted 和通知语义保持 | 事后重建也有 118 条、告警前五条相同 |
