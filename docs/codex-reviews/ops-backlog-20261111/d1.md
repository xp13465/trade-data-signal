## 实现合同

两个 sync 在非 DRY_RUN 初始化独立 UUID run。四条原有自然路径全部接线：幂等迁移 `migration/ALTER`、逐页哈希 `hash_prefetch/SELECT`、逐文件导入 `import/IMPORT`、COUNT `count_verify/SELECT`。import 只增加 `--json` 输出开关，不增加 HTTP/SQL 调用。凭据预检、生成器、业务字段、增量算法、COUNT 判据、重试次数和失败状态工具均保持既有语义。

默认位置 `$REPO/data/d1_metrics_evidence/<run_id>.json`，可显式设置 `D1_METRICS_DIR`。目录 0700，文件及锁 0600。每 call 保存 `run_id/call_id/code_ref/script/table_labels/stage/operation/start_utc/end_utc/attempt/exit_code/status/metrics_status/results`。code_ref 是运行树 Git HEAD；非 Git 环境为 null+unavailable，它不证明工作树干净。结果保留 result_index、snapshot_index、scope、结果 status、query_id（只有返回且符合受限 ID 字符格式才保存）、rows_read/written、duration 和毫秒单位、total_attempts、可取得的 query_count；缺失或非法值留 null 与机器可读 reason，真实返回 0 才记录 0。

- 导入始终按 **bundle** 保存，table_labels 为主表及 sync_meta/screener_meta 的影响标签，不是费用分摊。索引维护也可能在整包中。哈希/COUNT/ALTER 保留 statement scope；多 statement 每个结果独立保存，重复但不同序号的语句不去掉。
- HTTP/CLI 成败记录在 call.status/exit_code；单条返回成败在 results.status。容忍的 duplicate-column 迁移仍如实记录底层失败，外层幂等业务成功不改写它。业务 changed/new/removed 不复制进计数账，也不当成功写入数。
- 不计算跨 attempt 的“成功业务写入”总和。失败/超时可能已有部分效果；其已返回 meta 留在该 attempt，未知不能填零。total_attempts 不参与倍乘。
- 相同 call_id+attempt 重复提交不追加；stdout/stderr 镜像 JSON 去重。不同 JSON emission 可能是累计快照，也可能是部分结果，因此保留并标 `ambiguous_snapshots_do_not_sum`，不猜拆、不累加；正常一个结果数组的各语句不相互去重。缺失字段、纯文本错误、截断 JSON 不冒充零。
- 白名单提取不保存 SQL、参数、行结果、原错误文本、账号、database ID、bookmark、凭据或命令。两条原 stdout/stderr 以原字节交还既有调用者，原业务日志的保留策略未改。

## 本地故障与资源边界

调用输出经管道在内存暂存，再提取证据并重放 stdout/stderr。避免证据目录 ENOSPC 让 Wrangler 写 stdout 失败，从而误触发重试。现有单次秒数和外层重试预算仍传入；观察器对子进程组设相同 timeout，超时终止并回收进程组、返回 124。SQL 类型错误与原始返回码仍由原循环处理，最多次数由原 D1_RETRY_DELAYS 决定。

证据保存失败采用 **保留业务返回码并明确警告**：不把已经完成的业务写入改成失败，不因保存失败重放 SQL，也不声称证据完整。同步入口把诊断 FD 9 绑定原 stderr，故 COUNT/hash 的 `2>/dev/null` 不会吞掉证据警告。没有发送邮件/飞书或改监控。正常业务 exit 0 仅表示原同步+COUNT成功，不能据此断言计数证据完备。缺文件/警告由后续复核识别；本组不越界改 ops_monitor。

复用 `util_atomic.atomic_write_json(mode=0600)`，锁等待 2 秒、单次本地保存总预算 8 秒，写临时文件+fsync+rename，异常清掉临时项。每 run 最多 4096 calls、16 MiB，最多保留 128 个 run、30 天；随下一次写入清理自有 UUID 文件，不另设 cron。达到单 run 上限则拒绝继续记录并警告；旧 run 淘汰失败时拒绝新文件以保持数量有界。淘汰优先针对其他 run，不删当前 run 以腾容量；当前旧完整文件在写失败时保持不变。此留存是有界运维证据，不是永久审计库。

限制：输出目前在内存收集；16 MiB 是单流解析/持久化上限，不是 Wrangler 进程输出的硬内存上限。外部 SIGKILL/断电可能让正在执行的最后一个 call 无回执，不能由缺回执推定未执行；本实现没有新增远端确认或补跑。跨 stream 的不同快照无法恢复严格顺序，保持不可相加标记。未经线上自然轮验证，不声明已取得新增真实计数或节费收益。
