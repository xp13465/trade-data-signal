## 0. TL;DR 拍板摘要

**现在宽度(上涨/下跌家数、涨停数、AD线、恐贪指数)只算沪深两市 ~5185 只,不含北交所 339 只。要不要纳入?三个决策点,逐个拍板:**

| # | 决策点 | 现状 | 纳入后会怎样 | 我的倾向 |
|---|---|---|---|---|
| 1 | 北交所进不进主宽度(改家数口径) | 不纳(现状) | 涨跌家数绝对数变大(约 +6%),普涨/普跌日比率被北交所放大;**AD 线累计值永久断裂**;涨停判定必须加 30% 档否则天天误判 | **不建议现在全纳入**(动的是已上线冻结口径,§23.7) |
| 2 | 若进,2021-11 起的北交所历史要不要回填 | 无北交所历史 | 不回填=新旧口径断裂;回填=FAPI 全量历史覆盖需先验证(920 段 2024 才启用) | 要回填必须先把 FAPI 挂生产定时 + 验证全量历史 |
| 3 | 要不要单独出北交所宽度(不动现有宽度) | 无 | 新增 a_bj_width_* 独立指标,现有宽度零影响,历史独立可比 | **推荐这个**,风险最小,且管道通了未来想全纳入随时升级 |

**一句话:想"知道北交所多热"→ 选方案 C(单独出),不动冻结资产;想"全市场统一口径"→ 方案 A(全纳入),但要接受 AD 线/恐贪/涨停判定全动 + 历史回填改造,建议单独开一轮实施。** 详细影响面见下。

## 2. 关键实证数据(20260901,真实 DB)

### 2.1 北交所对涨跌家数的贡献

| 项 | 无北交所(mootdx) | 含北交所 | 变化 |
|---|---|---|---|
| 上涨家数 | 3081 | 3373(+292) | +9.5% |
| 下跌家数 | 1982 | 2027(+45) | +2.3% |
| 合计 | 5063 | 5400 | +6.7% |
| 上涨占比 | 60.8% | 62.5% | +1.7pp |

北交所当天极端强(292 涨/45 跌,平均 +3.16%,3 只顶格涨停 29.96-29.98%)。**北交所波动率远高于全 A(30% 涨跌幅),普涨日它更涨、普跌日它更跌,纳入后普涨/普跌日宽度比率会略微更极端。**

### 2.2 30% 档必要性实证(10 个交易日,北交所 339 只)

| 日期 | 涨>10% 只数 | 涨>20% | 接近30%涨停(29.5-30.5) |
|---|---|---|---|
| 20260901 | 14 | 5 | 3(920855/920895/920592 实测 29.96-29.98%) |
| 其余 9 日 | 每日常见 1-5 | 0-2 | 0-2 |

**结论:若用现在的主板 10% 档判北交所涨停,每天会误判 2-14 只"涨停"(实际是北交所 30% 规则内正常波动)。必须加 30% 档。** 20260901 三只顶格 29.98% 是 30% 涨停规则的硬证据。

### 2.3 北交所每日净涨跌(对 AD 线的影响量级)

| 日期 | 北交所净涨跌(up-down) | 全 A 净涨跌(mootdx) | 北交所占比 |
|---|---|---|---|
| 20260901 | +247 | +1099 | 22% |
| 20260824 | -184 | -2504(akshare) | ~7% |
| 20260821 | -138 | -1555 | ~9% |

AD 线 = cumsum(up-down) 从 2016 累计。**纳入后每天 AD 线永久加入北交所净差(量级为全 A 的 7-22%),AD 线水平值/趋势不可比,是历史断裂最大受害者。**

## 4. 历史序列可比性

- **2016-2021.10:无北交所是市场事实**(北交所 2021-11-15 才开市),任何数据源都没有,不存在漏采 → 这段历史天然不含北交所,不是口径断裂。
- **2021.11 起:北交所存在但 mootdx 未采** → 真正的断裂点在这里。
- **FAPI 回填能力**:`fapi_daily.py` 有 daily-k(10 年全量)重建档(库内最新落后 >=8 自然日自动切全量),理论可回填北交所自上市起行情。**但注意:920 代码段 2024 年才启用**(此前北交所是 43/83 段),FAPI 的 920xxx.BJ 历史是否覆盖 2024 前旧代码段行情,需全量抓取后实测验证 —— 列为实施前置验证项,当前 10 日窗口数据无法证实。
- **FAPI 供给现状**:`fapi_daily_raw` 表已建、10 日数据已在生产库,但 `launchctl list` **无 fapi 定时任务**(fapi-daily.plist 18:10 只写了模板未挂载)→ 北交所每日供给**目前不是自动的**,选 A/C 必须先挂 FAPI 定时。

## 6. 推荐 + 理由

**推荐:方案 C(单独出北交所宽度指标),作为第一步。** 理由:

1. **用户诉求是"了解清楚再拍板"** —— C 让用户先看到北交所宽度数据(北交所 339 只自己的上涨/下跌/涨停/成交额),零风险拿到信息,再决定要不要进化到 A。
2. **不动冻结资产(§23.7)**:方案 A 直接改现有宽度口径 = AD 线/恐贪/涨停数/前端全站数值变,其中 AD 线累计值断裂修复成本最高(lab.js 过热 toggle + daily_brief 都依赖它)。C 完全不碰,合规。
3. **管道先行,升级留门**:C 需要"FAPI 挂定时 + 北交所日线 → 北交所宽度"这条管道,和 A 完全同构。C 落地后,想全纳入 A 时,宽度计算加北交所 + 回填 + 30% 档即可升级,不返工。
4. **30% 档独立判定**:北交所宽度从一开始就用 30% 档,不会和主宽度 10% 档混淆。

**若用户最终选 A(全纳入)**,实施清单(建议单独一轮):①挂 FAPI 定时(18:10) ②FAPI daily-k 全量抓取,验证 920 段历史覆盖起点(2024 前 43/83 段?2021-11?) ③width_history 加 30% 档 + 纳入北交所 + 回填 2021-11+ ④全量重算 AD 线/恐贪百分位 ⑤更新公示文案(_WIDTH_CALIBER_TIP + REQUIREMENTS §8.5 + 前端口径 tip) ⑥全站回归(AD 线卡/恐贪卡/涨跌家数卡/涨停数卡/daily_brief)。

**需用户拍板的 3 个点**:①主宽度进不进北交所(A vs B) ②若要进,2021-11+ 历史是否回填 ③北交所单独展示位(C)是否要做。

## 7. 复现段

- 数据文件:`data/stock_daily.db`(mootdx_daily_raw / fapi_daily_raw)、`data/sentiment.db`(daily_metric)
- 关键查询(只读):
  - 当前宇宙:`SELECT date, count(*) FROM mootdx_daily_raw GROUP BY date ORDER BY date DESC LIMIT 8;`
  - 北交所家数:`SELECT count(DISTINCT code) FROM fapi_daily_raw WHERE code LIKE '920%';`
  - 北交所涨跌幅分布:`SELECT date, sum(pct_change>10), sum(pct_change>20), sum(pct_change BETWEEN 29.5 AND 30.5) FROM fapi_daily_raw WHERE code LIKE '920%' GROUP BY date;`
  - 北交所 up/down:`SELECT date, sum(pct_change>0), sum(pct_change<0), round(avg(pct_change),2) FROM fapi_daily_raw WHERE code LIKE '920%' GROUP BY date;`
  - 顶格涨停实例:`SELECT code, date, close, round(pct_change,2) FROM fapi_daily_raw WHERE code LIKE '920%' AND date='20260901' AND pct_change>25 ORDER BY pct DESC;`
