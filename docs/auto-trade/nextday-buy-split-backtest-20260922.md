## 1. 为什么挂单会输(S0 开盘直买仍最优)——盈亏来源分解

对「挂昨收+尾盘兜底」与 S0 之差做逐笔分解(545 笔):

| 类别 | 笔数 | 单笔平均折价/溢价 | 合计影响 |
|---|---|---|---|
| 低开 O≤PC,挂单按 O 成交(与 S0 同) | 343 | 0 | 0 |
| 回落触及 L≤PC,按 PC 限价成交(折价) | 129 | **-55 元/笔** | **省 7,037 元** |
| 未触及,尾盘 C×(1+SLIP) 兜底(溢价) | 73 | **+127 元/笔** | **多花 9,291 元** |
| **净差(挂昨收+tail − S0)** | | | **−2,254 元(−1.4%)** |

**根因:尾盘兜底的溢价(+9,291)大于限价折价的节省(7,037)。** 未触达的 73 笔是「高开不回落」的强势笔,尾盘价高于开盘价(日内方向统计:次日收盘平均高于开盘 +0.108%),兜底按尾盘价买反而比开盘价贵——挂单带来的折价收益被兜底溢价吃掉还有余。

**拆分挂单为什么更差(用户核心问题)**:拆分把资金拆到多个价格档,但每档独立判定——**深档(-0.5%/-1%)触达率低,兜底资金占比大幅上升**(挂昨收单兜底 13.4% → 拆3 35.7%),尾盘溢价成本被放大。拆2 昨1/2+-0.5%(兜底 25.6%)≈ 单档 -0.5%(37.8%)与单档昨收(13.4%)的加权平均,而兜底是负贡献 → 拆分结果必然落在两单档之间且偏差。**「把单拆细」没有创造任何结构性的独立价值,只改变了兜底资金的比例。**

补充验证:拆分各档的成交判定完全独立(每档 O/L/C 同一日行情),组合内没有「互为对手盘/优先成交」等联动,纯线性加权——数学上拆分结果必然在两端点之间,不可能优于最优单档。**拆分挂单在逻辑上无增益,数据上确认无增益。**

## 2. 与历史「昨收价挂单评估」的对照(口径差异必须诚实标注)

**用户记忆:「之前评估过次日用昨收价挂单效益比较好」** —— 出处 2026-09-10 报告(README 核心结论速查「挂昨收价限价单最优」)。

**但历史报告的挂单判定用错了日期(前视)!**

- 历史脚本(20260910 full_loop/gap_maxhold):`exec_date = buy_date 字段`,而 trades.json 的 buy_date 字段 **= 信号日**(信号日收盘才出信号,当日根本无法挂单)→ 旧评估实际模拟的是「信号日当天」挂单,是**前视/不可执行**
- 实操(nextday_plan_generator.py):信号日 T 收盘 → **T+1(real_buy_date)执行买入**,挂单价=昨收=信号日收盘
- 两口径入场日不同:信号日行情 vs 次日行情,高开率 40.0% vs 37.1%,成交分布也不同
- legacy 口径复现(与既有脚本一致):S0 +157,171 / 挂昨收+tail +155,035 / 挂昨收+skip +134,744 —— **legacy 口径下 S0 同样最优、挂昨收+tail 第二**;实操口径排序一致,差距略放大(legacy -2,136 → ops -2,254)

**结论:无论旧口径还是正确实操口径,「昨收价挂单」都不优于 S0 开盘直买(差 -1.4%),拆分挂单更差。** 历史报告「先挂昨收、尾盘兜底为最优补充」的推荐成立的前提是「当日无前视可挂」,实操口径下该推荐的增量收益(-1.4%)为负,只是金额很小(2,254 元/全史)。

另注意:`docs/kelly/position/kelly-nextday-open-backtest.md`(20260906)的「挂开盘下方 -1% 限价(保证成交)」+6.0 万是另一个口径:挂单价=**次日开盘价下方 -1%**(非昨收),且未触发按**开盘价兜底**(非尾盘市价兜底),假设更强(开盘价必然可成交)。本次任务用户点名的是「昨收价挂单」路线,两条路线基准不同,可类比但不可混读。

## 6. 诚实标注

1. **口径标注(tail 兜底)**:尾盘兜底按 C×(1+SLIP) 市价,SLIP=0.001;未计流动性不足场景(与既有报告同假设)。尾盘市价兜底是「实操真实假设」(PRD seq3 撤单市价兜底),**兜底价 ≠ 开盘价**,这是本次拆分挂单回测与 20260906「保证成交」模型的关键差异。
2. **挂单可操作性**:skip 类策略(未成交放弃)的成交不确定性最高(放弃 13.4%~56%);tail 类全部成交但兜底价可能高于开盘。**本任务所有策略(含 S0)均为「保证买入」视角;真实可执行性上,S0 一字板无法成交(ETF 极端罕见)与挂单滑点差(限价单以 O 或 P 成交,无滑点)互为对照。**
3. **前视修正**:历史 20260910 报告用信号日当天行情模拟挂单(不可执行),本次用 real_buy_date(次日)实操口径;两口径下排序一致(S0 > 挂昨收+tail > 拆分),差异仅为数值。
4. **宇宙口径**:S06+K=1+A 实操计划口径(a-to-h-rollover 541 笔权威口径 vs 本 545 笔差异 = 数据截止日推移新增笔,见 memory a-to-h-rollover-operable-541)。
5. **数据截止**:545 笔(485 笔卖/A 模式到期已回收,60 笔持有中按数据末日回收?——实际以脚本 cutoff=max(real_buy_date)=20260910;持有中笔按 sdate=None → 截止日回收)与既有脚本同款。
