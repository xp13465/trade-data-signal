# 凯利回测降低亏损穷举分析 v2（维度穷举 + 组合搜索）

> 生成日期：2026-08-08 ｜ 调研性质不 commit ｜ 数据源：`static-site/data/signal_kelly_trades.json`（32MB，mode A 去重 7472 笔全周期 / y5 近5年 6152 笔）
> v1（`docs/kelly-loss-reduction-analysis.md`）用 backtest 重跑 21 组模拟；v2 直接从 trades.json 原始逐笔记录做 13 维度穷举 + 31 组合搜索，补 v1 未覆盖维度，并交叉验证 v1 结论

## 0. 摘要（核心结论先讲）

**v2 三条核心增量发现：**

1. **"排除 3+5 月"是隐藏的高效过滤**——近5年 mode A 净盈亏从 +356K 升至 +452K（**+27%**），减亏 18.4%，净保留 127%。3月5月合计净亏 -95K（3月 -36K / 5月 -59K），是除 buy_aux 外唯一"排除后增收"的单条件。但系统性不强（6年里 3 月有 3 年亏损 3 年盈利，5 月同理），标注**过拟合风险，建议作可选 toggle 不作默认**。

2. **含月份过滤的组合全面优于 v1 最优**——`排除aux+MA60+排除3+5月`：净 +413K（净保留 116%）、减亏 72.8%、胜率 59.8%、盈亏比 1.60，全面优于 v1 最优 `排除aux+MA60`（净 +350K / 减亏 64% / 胜率 55.8% / 盈亏比 1.50）。减亏多 9 个百分点同时净盈亏多 18%，代价是月份过滤的过拟合风险。

3. **v1 结论交叉验证通过**——v2 用 trades.json 原始数据验证 v1 的 `排除aux+MA60`：净保留 98.3%（v1 报 98%）、减亏 64.1%（v1 报 64%），口径对齐，v1 结论可靠。

**v2 补 v1 未覆盖的 8 个维度结论：**
- `sell_reason`：mode A 99.1% 为"到期"（无止盈止损），维度无挖掘价值。mode B/C 有止盈但那是卖出策略非入场特征
- `track_tier`：各档（none/strong/related/approx）均净正收益，无可排除档；none 档净 +137K 反而最高
- `match_method`：overlap/kw 样本极小（25/30 笔）净负但不具统计意义；track_index 占 86% 主力
- `hold_days`：99.3% 集中在 8-10 天（mode A 固定持有期特征），无分布可挖
- `track_low_confidence`：仅 24 笔 True（0.4%），样本太小
- `指数大类`：sw 申万行业亏损总额最高（220K）但净正 +16K；海外/港股净正不应排除
- `亏损幅度`：>5% 的大额亏损占 12.8% 笔数但占 58% 亏损金额（印证 v1 止损无效结论）
- `rating`：low 档占 78.8% 是最大亏损源（914K），但排除它牺牲 72% 利润，太激进

## 1. 数据口径

### 1.1 数据源差异

| 项 | v1 | v2 |
|----|----|----|
| 数据源 | `signal_kelly_backtest.py` 重跑 21 组模拟 | `signal_kelly_trades.json` 原始逐笔记录 |
| 基准笔数 | 6152（y5 mode A） | 6152（y5 mode A，去重后一致） |
| 全周期 | 未报 | 7472 笔（2016-2026） |
| 分析方式 | 固定 21 组条件模拟 | 13 维度穷举 + 31 组合搜索 |

- trades.json 结构：顶层 `quadrants` 含 16 象限，分 4 组 partition（rating×3 + etf×4 + sig×4 + mkt×5），每笔 trade 在每组 partition 各出现一次；每象限含 A-F 6 模式（不同卖出策略：A=10天到期 / B=止盈+到期 / F=15天到期 等）
- mode A 去重：取 rating_high+mid+low 三象限并集（partition 不重复），全周期 7472 笔，y5（≥20210810）6152 笔，与 v1 基准一致
- 基准指标（y5 mode A）：净盈亏 +356,321 ｜ 总盈 +1,451,870 ｜ 总亏 -1,095,549 ｜ 胜率 52.9% ｜ 盈亏比 1.18

### 1.2 口径定义

- **减亏%** = 被过滤 trades 的亏损额 / 基准总亏损额（正值=减亏比例）
- **净保留%** = 过滤后净盈亏 / 基准净盈亏（>100% 表示过滤后增收）
- **利润保留%**（v1 口径）= 净保留%，非"总盈利额保留"
- 基准总亏损 = -1,095,549 元（所有亏损 trade 的 profit 之和）

## 5. 月份过滤专题（过拟合风险评估）

### 5.1 统计效果

- 排除3+5月：净盈亏 +356K → +452K（+27%），减亏 18.4%，净保留 127%
- 3月合计净 -36K（胜率 44.1%），5月合计净 -59K（胜率 34.7%）
- 4月最好（+82K，胜率 69.6%）→ 春季躁动规律：4月顶峰→5月回调

### 5.2 稳健性结论

- 3月：6年里 3 年亏损（2022/2024/2025），3 年盈利（2023/2026）
- 5月：6年里 3 年亏损（2024/2025/2026），3 年盈利（2022/2023）
- **并非每年都亏**：2022-2023 熊市 5 月反而盈利（+4.5K/+4.1K）
- 2026年5月亏损极大（-49.5K）拉高了5月的平均亏损，若剔除2026则5月仅净 -9.7K

### 5.3 建议

- 作**可选 toggle**（前端开关，用户自选），不作默认过滤
- 理由：统计有效但样本年数少（6年），系统性不强，可能过拟合 2024-2026 的春季回调周期
- 若实施，建议标注"季节性过滤，基于历史规律，不保证未来有效"

## 附录 B：数据结构说明

- `signal_kelly_trades.json` 顶层：`generated_at` / `buy_amount`(10000) / `period_cutoffs`(y1/y3/y5/y10/all) / `fields`(20字段) / `quadrants`
- `quadrants` 含 16 象限，分 4 组 partition：
  - rating（3）：rating_high/mid/low（信号评级，partition 求和=7472 unique）
  - etf（4）：etf_strong/related/approx/has_track（ETF档，求和=7100，缺372笔 none 档）
  - sig（4）：sig_main/aux/special/backup（信号类型，求和=7472）
  - mkt（5）：mkt_a/hk/global/industry/concept（市场大类，求和=7472）
- 每象限含 A-F 6 模式（A=10天到期 / B=止盈+到期 / C=止盈+到期 / D=止盈+到期 / E=5天到期 / F=15天到期）
- 每笔 trade 是按 fields 顺序的数组：`[signal_date, index_id, signal, buy_date, sell_date, etf_code, etf_name, track_tier, track_score, match_method, track_low_confidence, buy_price, sell_price, shares, profit, return_pct, hold_days, sell_reason, current_price, market_state]`
