如何判断一个绿灯

任务触发 → 输入就绪 → 消费者可读 → 业务结果完整 → 发布验证 → 服务可用。每个阶段必须有当前窗口内的证据；进程存在、exit 0、文件更新或邮件发出，都只是其中一层事实。

当前预览的“业务健康”统一为未知。未来接入后，证据过期、采集器失联与来源冲突也必须变为未知，而非保留绿色。

私人原始证据不随页面公开。此文件无需网络和账号；实时采集、认证、操作控制与部署是后续实施范围。
