### 3.1 ③ 的倒置守卫(对齐 #217② 先例,不是只改一个常数)

`scripts/fapi_bj_width_export.py` 新增:

```python
_R2_UPLOAD_TIMEOUT = 900          # 外层: 内层 600 + 300 余量
_R2_UPLOAD_TIMEOUT_MARGIN = 300

def _r2_upload_timeout() -> int:
    """本层 subprocess 超时;若与内层 R2 HTTP 超时构成倒置/零梯度 ⇒ 自动抬升 + 告警。"""
    try:
        http_to = int(os.environ.get("R2_UPLOAD_HTTP_TIMEOUT") or "30")
    except ValueError:
        http_to = 30
    if _R2_UPLOAD_TIMEOUT <= http_to:            # 倒置 或 零梯度(相等)
        want = http_to + _R2_UPLOAD_TIMEOUT_MARGIN
        print(f"⚠ ... 外层 {_R2_UPLOAD_TIMEOUT}s <= 内层 HTTP 超时 {http_to}s(梯度倒置/零梯度), "
              f"自动抬升到 {want}s(内层+300s 余量)", flush=True)
        return want
    return _R2_UPLOAD_TIMEOUT
```

- 调用点 `_to = _r2_upload_timeout()` → `subprocess.run(..., timeout=_to)`,超时消息同步改动态值(残留硬编码 `600s` 已清零,自测 [B])。
- 判据含 **`<=`**(相等也判零梯度,这正是点③改前的形态)⇒ 未来若有人把 `_R2_UPLOAD_TIMEOUT` 调回 600/300/120,**自动抬升 + 打警告**(自测 [A] 三个回归用例覆盖)。
