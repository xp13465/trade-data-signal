# #223-⑤ 修云上 systemd「外层硬杀」零梯度 —— 实施报告(2026-10-06)

> 任务:用户已批准的 #223-⑤。**只抬云上 unit 的 `TimeoutStartSec`,Python 侧那两处 `timeout=600` 一个字未动**(抬 Python 侧 = 反向操作)。
> 分支:`feat/223-5-systemd-outer-20261006`(worktree 隔离)。
> 判据(来自 `docs/ops/217-223-threshold-copy-review-20261006.md` §11):**激进的必须比优雅的慢**。L1=Python subprocess 超时(被 `except TimeoutExpired` 捕获,优雅);L2=systemd `TimeoutStartSec`(**无进程内捕获的硬杀**)。梯度原则 **L2 > L1**;本例是 `600 == 600` 零梯度 + systemd 计时自 unit 启动起算(**早于** sync 启动)⇒ systemd **必先杀** ⇒ 「✗ 超时」日志永不打出。

## 0. 一句话结论

`trade-fetch-news.service` 与 `trade-daily-brief.service` 的 `TimeoutStartSec` 由 **600** 分别抬到 **1080 / 1740**(= 内层串行合计 + 300s 余量),云上 `edit + daemon-reload` 已生效(18min / 29min),**未 start/stop/restart 任何 unit、零外发、零 R2 写**;仓库快照 + doc §2 已同步,三项审计全 PASS。

### 1.5 新值算式(凭据=代码 + .env)

**内层串行合计** = 单次运行内**串行**的、有 `except TimeoutExpired` 优雅处理的 subprocess 超时之和(即 L1 链;HTTP/AI 调用属另一层,不计入)。范围依据 = 复审报告 §11 的 L0/L1/L2 分层。

**trade-fetch-news.service** — `sync_news_digest_live()`(`scripts/fetch_news.py:638`)内串行两段:

| L1 段 | 位置 | 值 |
|---|---|---|
| R2 上传 `upload_r2.py --skip-if-locked upload-data-files` | `fetch_news.py:732` | `120 + R2_UPLOAD_SKIP_RETRY_SECS` = 120 + 60 = **180** |
| staticdata 同步 `staticdata_sync.sh news-fetch` | `fetch_news.py:755` | **600** |
| 串行合计 | | **780** |
| 取数来源 | | `.env` 未设 `R2_UPLOAD_SKIP_RETRY_SECS` ⇒ 默认 60(`fetch_news.py:717`) |
| **新值 = 780 + 300** | | **1080** |

**trade-daily-brief.service** — `gen_daily_brief.py` `main()` 内串行四段:

| L1 段 | 位置 | 值 |
|---|---|---|
| R2 上传(主数据) | `gen_daily_brief.py:3116` | **120** |
| staticdata 同步(主数据) | `gen_daily_brief.py:3165` | **600** |
| R2 上传(run_log) | `gen_daily_brief.py:4431` | **120** |
| staticdata 同步(run_log) | `gen_daily_brief.py:4432` | **600** |
| 串行合计 | | **1440** |
| **新值 = 1440 + 300** | | **1740** |

> `run_daily_brief.sh`(ExecStart)无 shell `run_to`(实测空),systemd 是唯一外层;`staticdata_sync.sh` 其余调用方(`intraday_snapshot.sh:202`)走 `STATICDATA_SYNC_NONBLOCK=1` 且其外层 `trade-intraday-snapshot.service TimeoutStartSec=0`(无限),**无天花板、无倒置**(见 §5 举一反三)。
