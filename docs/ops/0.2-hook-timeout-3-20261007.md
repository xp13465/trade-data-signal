`scripts/agent_dispatch_cron_reminder.py`(PostToolUse(Agent) hook)机检项由 **2 项 → 3 项**:新增 ③ 判「派单 prompt 是否含 `timeout` 约束标记」,对所有 subagent_type 生效(同 ①,不只 implementer)。文档镜像(CLAUDE.md §0.2、ZCode 代班 skill)已同步。负向探针实测能红。
