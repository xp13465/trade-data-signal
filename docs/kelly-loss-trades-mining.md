## 0. 摘要（核心结论先讲）

**方法论核心**：用户要的不是"单看亏损"，而是"亏损交易有、盈利交易没有"的**差异化**共性。本报告用 `over_rep = (该值在亏损中占比) / (该值在盈利中占比)` 量化差异化，>1 表示亏损过代表。一个有独立价值的降亏标志 = `over_rep 高` + `排除后净影响为正`（排除亏损额 > 排除盈利额）+ 系统性稳定（非单一年份/过拟合）。

**三条核心增量发现：**

1. **"排除 3+5 月"被严重低估**——全模式下它是**单条件净影响最高**的 toggle（+527,996 元），降亏 18.4% 仅损盈 8.7%（比值 2.11，全场最高）。且 `03/05月 + 非2022/2023 = net -601,558`，证明是**结构性**季节效应而非熊年假象。用户评价"有点价值"→ 实际是**最有价值的 toggle**。过拟合风险：05月 2021-2023 盈、2024-2026 亏（近年 shift），非逐年稳定，建议作可选 toggle。

2. **"排除低评级"是破坏性的，用户判断正确**——rating=low 全模式净 +810,319 元（正收益），排除它降亏 82.3% 但损盈 72.0%，**净影响 -810,319**（最大破坏）。逐年验证：低评级 2023(-183k)→2024(+160k)→2025(+901k) 确有递增趋势，但 2022(-244k)/2026(-113k) 仍亏，**非每年都赚**。结论：低评级是周期性盈利群体，直接砍 = 把牛市利润一起砍掉，价值不大且破坏性强。

3. **新增两个高性价比交叉标志（v2 未发现）**：
   - **`buy_aux + 03/05月`**：净影响 +257,547，降亏 7.3% 仅损盈 2.9%（**比值 2.52**），over_rep 1.765。最"外科手术式"的标志。
   - **`buy_special(追关注) + MA60熊市`**：净影响 +264,700，降亏 8.3% 仅损盈 3.6%（比值 2.31），over_rep 1.618。追涨信号在熊市是净亏损 -264,700 元的"雷区"。

**最佳组合**：`排除buy_aux + 03/05月 + buy_special熊市` → PF 1.296→**1.821**，净影响 **+653,067**，降亏 53.1%，损盈 34.1%（平衡最优）。若要最高 PF：`01/03/05/11月 + buy_aux` → PF **1.960**，降亏 61.8%（但损盈 42%，切得深）。

**对现有 4 toggle 的数据评价**（见 §4 详）：
| toggle | 用户评价 | 数据结论 | 净影响 | 推荐 |
|--------|----------|----------|--------|------|
| 排除 3+5 月 | 有点价值 | **最有价值**（被低估） | +527,996 | 强推（可选，附过拟合提示） |
| 排除辅关注 buy_aux | 相对合理 | 确认合理（唯一净负信号类型） | +148,374 | 保留 |
| MA60 多头择时 | 有点价值 | 全模式**净负**（v2 mode-A 近中性），降亏 47% 但损净利 | -148,749 | 重风险可留，重净利应弃 |
| 排除低评级 | 价值不大 | **破坏性**（损净利 810k），低评级周期性盈利 | -810,319 | 不推荐 |

## 1. 数据口径

### 1.1 数据源与去重
- `signal_kelly_trades.json`：dict{generated_at, buy_amount=10000, period_cutoffs, fields(21), quadrants}
- `quadrants[16象限][6模式A-F] = list[trade]`，trade 为 21 字段位置数组
- 16 象限分 4 维 partition：rating(3,互斥覆盖全体) / etf(4,子集) / signal(4,互斥覆盖全体) / market(5,互斥覆盖全体)。**同一笔 trade 在 4 维各出现一次**，跨维去重后得唯一集
- 6 模式：A=固定10天 / B=3%止盈 / C=5%止盈 / D=7%止盈 / E=持有5天 / F=持有15天
- **去重 key**：`(signal_date, index_id, signal, buy_date, etf_code, sell_date, sell_reason, mode)`。raw 172,638 → 去重 **43,656 unique trades**（rating 维与 sig 维都 = 43,656，互斥覆盖确认去重正确）
- **7,276 unique signals × 6 modes = 43,656 trades**（每信号生成 6 个卖出策略结果）

### 1.2 21 字段
`signal_date, index_id, signal, buy_date, sell_date, etf_code, etf_name, track_tier, track_score, match_method, track_low_confidence, buy_price, sell_price, shares, profit, return_pct, hold_days, sell_reason, current_price, market_state, rating`

### 1.3 口径定义
- **profit>0 盈利 / profit<0 亏损**（无 0 值）
- **over_rep（差异化指数）** = `(该值在亏损交易中占比) / (该值在盈利交易中占比)`。>1 = 亏损过代表（差异化共性），≈1 = 无差异，<1 = 盈利过代表
- **降亏%** = 排除交易的亏损额 / 全局总亏损额
- **损盈%** = 排除交易的盈利额 / 全局总盈利额
- **净影响** = -(排除交易的净盈亏)。正值 = 排除后总净利增加（好标志）；负值 = 排除后总净利减少（坏标志）
- **比值** = 降亏% / 损盈%，>1 表示排除亏损多于盈利（性价比高）

## 6. 关键诊断与局限

### 6.1 亏损机制画像（综合诊断）
1. **80% 亏损额来自大亏(>=3%)**，大亏 68.5% 发生在满期持有（hold=10天）
2. 大亏过代表特征：buy_aux(1.308)、05月(1.849)、熊市(1.200)、none档(1.164)、mode F(1.155)
3. 亏损集中在"弱势信号 + 弱势环境 + 满期持有"：buy_aux/追涨在熊市/05月持有到期 = 大亏高发
4. 止盈策略（B/C/D）有效锁盈（止盈 0 亏损），但未触发的"到期"亏损率高（mode B 73%）

### 6.2 过拟合风险提示
- **月份标志**：05月近年 shift（2021-2023盈/2024-2026亏），非逐年稳定。建议可选 toggle + 监控，非默认硬排除。
- **指数黑名单**：粒度过细，赛道周期性强（新能源 2022-2024 熊），样本 300-684/指数。建议观察名单非排除。
- **交叉标志**：双条件交集样本缩小（buy_aux+03/05月 n=2,166），统计波动大。需前向验证。
- **全模式 vs mode-A**：本报告全模式（43,656笔）与 v2 mode-A（7,472笔）结论在 3+5月(降亏18.4%一致)、low rating(破坏性一致)、buy_aux(合理一致)上互相印证；MA60 全模式净负 vs mode-A 近中性是**模式依赖差异**，实施时按所选卖出策略评估。

### 6.3 调研边界
- 仅静态分析历史交易，未做前向 walk-forward 验证。推荐组合的历史表现不保证未来。
- 未模拟"排除后信号减少致仓位集中度变化"对 Kelly 仓位的影响（排除信号后资金分配到剩余信号，可能提高单笔仓位）。
- rating 评分/track_score 等特征在历史回测中是事前已知的（信号生成时计算），可作 toggle；sell_reason/hold_days 是事后结果，仅诊断。
- "无/0/不可改善"类结论已多维度验证（§2.14 信号-买入间隔全0=无信息非未查；09月差异化但净正=已验不宜排除；track_score 非单调=已验全5档）。
