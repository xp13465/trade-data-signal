## 3. 手段设计(任务2):业界仓位管理调研 + 4 种可实现手段

### 3.1 业界仓位管理方法(WebSearch,§5.1 精神)
搜索覆盖 fixed fractional risk / position cap / exposure limit / concentration limit 等:
- **单笔风险固定百分比**(1-2% 账户净值,止损距离决定仓位)——凯利系(本项目半凯利)同理,业界共识凯利全仓过激,用半凯利/四分之一凯利。
- **组合敞口上限**(portfolio exposure cap):新仓使总敞口超 cap 则缩小仓位——对应本项目"持仓≤20万"正是**组合级敞口上限**。
- **集中度限制**(单标的不超 5-10%)、**combined open risk check**(新仓+已有敞口合计超限则拒)。
- 关键映射:本项目手段A=exposure 超限拒绝开仓;手段B=超限时强制轮动(卖旧买新);手段D=时间/价格止盈止损提前退出。

### 3.2 四种手段的实现逻辑(事件序列上如何改)

**手段C(动态缩每笔金额)先否决(§5.1 口径对比,数据证明)**
- 每日池每日恒投 10,000,缩小每笔金额只是把"当日 N 信号"的等分变小,不改"每日总投 10,000"。
- 更本质:**峰值持仓/单次本金 是标度不变的**——把所有金额同乘 f,峰值变 f×136万、单次本金变 f×1万,比值仍是 136x。纯缩放永远改不了倍数,必须改变**交易选择或持仓结构**。故 C 不可行。

**手段A:当日新买入若使持仓超 cap 则当日不买(砍当日信号)**
- 事件序列:逐日推进,先处理当日自然卖出(释放资金),再判 `当前持仓 + 当日总投(10000) > cap ?` 是则**整日砍掉**(丢弃当日信号,不买不卖),否则买入。
- 不引入任何强制平仓利润假设(砍掉的信号从未买入,不贡献盈亏)。诚实、实现简单,但会错过组合满仓期的信号(见 §5 按年分解:大牛年 2017 全跳、2024 为负)。

**手段B:持仓达 cap 后强制平掉最久持仓回到 cap 内再买入(FIFO)**
- 事件序列:同 A 逐日推进;若 `当前持仓 + 10000 > cap`,则按 **buy_date 最久者优先(FIFO,唯一无前视的选择)** 强制平仓,平到 `当前持仓 + 10000 ≤ cap` 再买当日信号。
- 强制平仓的盈亏按模型实现:b0=0 利(最保守)/ b1=按持有时间线性比例(中值)/ b2=全额(上界)。
- 优势:组合不闲置,持续交易,保住大牛年;代价:强制平仓真实盈亏不可知,依赖模型假设。

**手段D:提前止盈/止损使持仓降下来(持仓截断)**
- 事件序列:**每笔**持仓超过 H 天(按 cap/单次本金折算)即强制卖出,与组合是否满仓无关。
- 相当于"时间止损/止盈",把 G 的 21-100 天盈利持仓全部截到 20 天。数据证明此手段摧毁利润(G/H/I b0 全负),与用户"不要变成 B 模式 3%止盈全负"的直觉一致。

4. 实现层面:B 需维护 FIFO 持仓队列,实时判断"当前持仓+当日新投>cap 则平最久";A 只需"满仓不买"(更简单但收益低);D 最简但数据证伪。

**保守口径建议**:由于强制平仓真实盈亏不可知且短持仓为负,b0(平仓=0)作为保守基准值;若实施时希望乐观,以 b0-b1 区间(G 191K-401K / 95.7%-200%)评估,不把 b1 当承诺值。

## 8. 最终建议与诚实标注(任务6)

### 建议
1. **给 G/I 模式加手段B 持仓上限(默认 20万=20×单次本金,K=1)**。用户"G 不可操作"的判断正确,但 cap 后 G 反成最优可操作模式(G B b0 95.7% 收益 / 191K 净利)。

### 诚实标注(哪些可靠 / 哪些机制性)
**可靠(结构稳定,多模型下一致)**
- G/I 三模式峰值 45-148x 全超 20x;hold≤20 天交易全负、利润全在 21-100 天——跨模式一致的持仓结构。

**机制性 / 依赖假设(必须注明)**
