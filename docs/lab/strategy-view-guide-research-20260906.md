## 3. 双视角呈现形式建议(3 候选,不写代码)

### 形式 A · 静态小结卡(推荐,成本最低)

首页 help 双形态「一句话原理」后 + 凯利区「分投资习惯」表上方,加带边框小结卡:

```
┌─ 📐 按投资周期选 ──────────────────┐
│  近1年冲收益 → A 固定10天   29.62% 全模式第1 │
│  长期稳健   → H 满仓不买  230.83% 全周期第1 │
│  (H 最简:无强平,到5万停买)              │
└────────────────────────────────┘
```

- 优点:改动局部、双形态好同步、无交互逻辑;缺点:静态文案,用户不可自行切换验证。

### 形式 B · 双视角对照表(凯利区建议指南升级形态)

改造「分投资习惯」表格,加「时间窗口」两行:

```
│ 投资周期  │ 建议     │ 关键数字                                │
│ 近1年短线 │ A固定10天 │ 29.62% 全模式第1 · 10w/10x 可操作 · 零盯盘 │
│ 长期持有  │ H满仓不买 │ all 230.83% 全周期第1 · 5x 最简 · 负年仅1个 │
```

- 优点:信息密度高、与既有「投资习惯」表并列同构;缺点:仅凯利区有表,首页 hoverpop 塞表不友好。

### 形式 C · 周期联动高亮(远期可选,需用户拍板)

凯利区全信号表/按年表加周期联动:切「近1年」高亮 A 行、切「全部/10年」高亮 H 行,配引导「👀 切周期看谁第一」。

- 优点:数据驱动、用户可自行验证(呼应 §5.1);缺点:动全信号表行高亮 = 动已发布核心功能,**§23.7 版本功能冻结契约要求用户确认后才可改**;实施成本最高。

### 推荐组合

主推 **形式 A 静态小结卡**(落点 1 首页 help 双形态 + 落点 2 凯利区建议指南两处同步);形式 B 作为凯利区建议指南的可选升级形态;形式 C 列远期待拍板(需用户确认,§23.7)。
