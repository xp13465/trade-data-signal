## 0. 摘要（三个核心答案）

### 0.1 次日开盘买入的成本极低：净利 -0.01% ~ -0.6%，不是"竞价高开吃掉利润"
用户担心的"次日开盘买入会因竞价高开跳空+滑点产生差额"——**数据否定了系统性高开**：
- **信号次日跳空均值仅 +0.031%、中位数 0、标准差 0.97%**（7,412 笔干净样本）；高开 >1% 仅占 6.2%，高开 >2% 仅 2.3%，低开 44.3%。
- **追关注（buy_special）信号次日跳空 -0.016%（不系统高开）**，主关注（buy）仅 +0.046%——"信号次日必高开"的直觉不成立。
- **次日开盘 vs 当日收盘的净利差**：每日池等分口径 ≈ **-0.01%（几乎为零）**；每笔固定 1 万口径 **-0.57%**（-22,383 元，-3.02 元/笔）。**换到真实跟单口径的代价可忽略。**

### 0.2 每日池等分天然对冲了跳空成本；每笔固定 1 万才全量承担
- **每日池口径（主口径）**：拥挤日（多信号日）平均跳空略正（5-6 信号日 +0.12%~+0.23%），但每日池把每笔金额摊成 10000/N，**跳空成本随信号数被摊薄**；单信号日（547 天）平均跳空略负（-0.025%），成本反而为负。两者抵消 → 每日池下次日开盘 vs 收盘净利差 ≈ 0。
- **每笔固定 1 万口径**：拥挤日每个信号都全仓 1 万，高开成本全量叠加 → 净利 -0.57%。**若用户实际是"每信号固定金额"而非"每日资金池"，次日开盘成本略升但仍极小。**

### 0.3 等回踩有真实空间：挂开盘下方 -1% 限价单（保证成交模型）净利 +5.8~6.0 万
- **次日盘中回踩空间显著**：次日最低平均比开盘低 **-1.06%**（中位 -0.75%），**87.9% 的交易日日内最低点低于开盘**。
- **次日最低价买入（理论最优上界，不可实现）**：K=1 净利 +94.9 万（vs 开盘 +78.5 万，+16.4 万）、收益率 59.30%（vs 49.04%）。
- **可实现的限价对冲**：开盘下方 -1% 限价单（未触达则按开盘价兜底保证成交）→ K=1 净利 +84.5 万（+6.0 万）、收益率 52.81%（+3.8pt），触达率 39.8%。**这是"怎么跟信号"的最优操作建议。**

## 1. 口径与方法

### 1.1 数据源与定价
- 信号与基线交易：`signal_kelly_trades.json`（21 字段，9 卖出模式 A-I，按评级 3 象限分区）。基线 `buy_price` = 信号日 `accum_nav`（累计净值，收盘口径）× (1+0.1% 滑点)；`sell_price` = 卖出日 `accum_nav` × (1-0.1%)；profit 已含佣金万3/最低佣金 5 元/沪市过户费万0.1。
- 次日开盘价：`etf_daily.open`（原始价）。**覆盖率 100%**（7,414 基笔全部有次日交易日的 open，无缺口）。
- 次日开盘重定价：`次日开盘 accum_nav 等价值 = 信号日 accum_nav × (次日原始 open / 信号日原始 close)`（gap 比例，scale-free，正确处理分红；卖出价/卖出日保持记录不变）。
- 费率按 `simulate_trade.py` 的 `_buy_with_fees`/`_sell_with_fees` 逐笔重算（佣金/最低佣金/过户费/滑点）。

### 1.2 口径矩阵（穷举全跑）
| 轴 | 取值 |
|---|---|
| 主对比 | 当日收盘买入（完美基线） vs 次日开盘买入（真实） |
| 资金口径 | 每日资金池等分（主推） + 每笔固定 1 万 |
| K 档 | 买全部 / K=1 / K=2 / K=3 / K=4 |

| 对冲（可选） | 次日最低价（理论最优上界）+ 开盘下方 -0.5%/-1%/-2% 限价单（保证成交） |

### 1.3 卖出处理与诚实标注（近似说明）
- **G/H/I（信号驱动卖出）精确**：卖出由指数后续 sell/sell_stop_loss 信号触发，与买入价无关；次日开盘买入后卖出的日期/价格与记录完全一致。
- **A-F（固定持有/止盈）二阶近似**：保持记录卖出日/卖出价不变。真实"固定 N 天"会因买入晚 1 天而卖出晚 1 天（本报告卖早 1 天）；B/C/D 止盈模式买入价更高时止盈触发更晚（本报告按记录的早止盈=对次日口径略乐观）。量级二阶，不影响结论。
- **收益率（净/峰值持仓）对买入时点敏感**：买入晚 1 天使并发持仓峰值略降（机械效应），K=1 峰值 161.0万→160.0万，收益率 48.88%→49.04% 的"提升"是分母变小，非真实改善（净利实际 -2,440 元）。

### 1.4 数据质量处理（份额折算伪跳空，关键）
- 检测到 2 笔 **|gap|>20% 的份额折算伪跳空**（非真实可交易跳空）：
  - 512560 军工ETF易方达 2021-11-15（close 1.642→open 0.854，-48%）：后续价格全部 ~0.84，为 2:1 份额折算。
  - 159739 云计算ETF鹏华 2026-08-03（close 1.576→open 0.777，-51%）：同上。
- 基线 profit 用 accum_nav（已折算调整）不受影响；但 gap 调整用原始价会把这两笔的次日买入价低估 50%，**虚增次日收益 +17,605 元**（若不剔除，每日池口径会得出"次日更优 +2,014 元"的错误结论）。
- **本报告全部数字均剔除这 2 笔**（基线与次日同时剔除，可比）；极端值表格保留说明。

## 6. 等回踩空间与限价对冲（"怎么跟信号"的操作建议）

### 6.1 次日盘中回踩空间（次日最低 vs 次日开盘）

| 统计量 | 值 |
|---|---|
| 回踩幅度均值 | **-1.06%** |
| 中位数 | -0.75% |
| 日内最低点低于开盘的交易日占比 | **87.9%** |
| 日内方向（次日收盘 vs 次日开盘） | +0.108%（次日收盘略高于开盘） |

**读法**：信号次日**几乎每天（87.9%）开盘后都有回踩**（平均 -1.06%），且次日整体趋势是"低开高走"（收盘 +0.11% 高于开盘）。**开盘价买入在统计上是"买在日内高位"**——等回踩存在真实空间，但需要正确执行。

### 6.2 限价单对冲（保证成交模型：低点触及限价按限价，否则按开盘价兜底买入）

| 策略 | 买全部净 / 收益% | K=1 净 / 收益% | K=2 净 / 收益% |
|---|---|---|---|
| 次日开盘直接买 | +657,218 / 38.28% | +784,576 / 49.04% | +694,404 / 43.27% |
| 挂开盘下方 -0.5% | +704,523 / 41.04% | +832,928 / 52.06% | +742,034 / 46.23% |
| **挂开盘下方 -1%** | **+715,537 / 41.68%** | **+844,931 / 52.81%** | **+753,074 / 46.92%** |
| 挂开盘下方 -2% | +695,803 / 40.53% | +823,314 / 51.46% | +733,341 / 45.69% |
| 次日最低价（理论最优上界） | +814,198 / 47.42% | +948,809 / 59.30% | +853,381 / 53.17% |

**限价触达率（当日最低 ≤ 限价）**：-0.5% → 62.2%；-1% → 39.8%；-1.5% → 24.5%；-2% → 14.5%。

**诚实标注**：
- **-1% 限价单是"收益-成交率"最优折中**：净利 +58~60 千元（+7.7%~+8.9% 净利）、收益率 +3.4~3.8pt，约 40% 的交易日真能吃回踩，60% 按开盘兜底买入（无踏空）。
- -2% 限价触达率骤降到 14.5%，且吃到的回踩更深但更少，净利反而回落（+1.8 千元 vs -1%）——**限价挂太深不划算**。
- **次日最低价是理论最优上界**（需恰好最低点成交，不可实现），只作上限参考，不作策略推荐。

## 7. 结论与建议

### 7.1 是否值得改"次日开盘"口径？→ 值得（成本极小，且是真实跟单口径）
- 换口径的代价：每日池 ≈ -0.01%、每笔 1 万 ≈ -0.57% 净利，**收益率基本不变**。任何 K/toggle/卖出模式的相对排序都不变。
- **关键**：收盘价买入本来就是不可实现的（信号收盘后发出，收盘价已无法成交）。次日开盘口径是**真实可执行的口径**，成本却几乎为零——**没有任何理由继续用"收盘买入"的完美假设做决策**。后续回测/前端展示建议默认改"次日开盘"口径（数据已 100% 覆盖，实现成本低）。

### 7.2 怎么跟信号（最优操作）→ 开盘不追，挂开盘下方 -1% 限价，未触发按开盘价兜底
- 挂开盘下方 -1% 限价（保证成交模型）是数据最优折中：K=1 净利 +84.5 万（vs 直接开盘买 +78.5 万）、收益率 52.81%，触达率 40%。
- 不建议挂 -2% 或更深（触达率骤降、净利回落）。
- 港股/全球类信号（高开 15%+）建议限价更保守（如 -1% 优先）；A股类信号跳空≈0，限价 -1% 也 OK。
- 拥挤日（多信号日）平均高开略多，但每日池等分已天然摊薄；若用每笔固定金额，拥挤日优先挂限价。

### 7.3 对现有结论的影响 → 无影响（口径只是"换更真实的定价"）
- 每日池买全部消除爆炸（171.7 万峰值）、K=1 数据最优（48.88%→49.04%）、K=2 推荐默认（43.18%→43.27%）、降亏只推 a45/exclBear、B 模式全负——**所有基线报告的结论在次日开盘口径下原样成立**。

### 7.4 一句话推荐
> **信号收盘后固化、次日开盘买入是真实且几乎零成本的跟单口径（净利 -0.01%~-0.57%、收益率基本不变）。操作上别在开盘追：挂开盘下方 -1% 限价单（未触发按开盘价兜底），约 40% 的交易日能吃到平均 -1.06% 的回踩，净利 +5.8~6.0 万、收益率 +3.4~3.8pt。信号次日不系统高开（均值 +0.03%、追关注 -0.016%），"竞价高开吃掉利润"的担忧不成立。**
