## 七、风险提示(实施时注意)

1. §23 系列指针化后,非对应角色的会话不再拿到规范原文,只有摘要。摘要必须含「触发词+核心一句话+验收口径一句话+指针」四要素(本报告四节指针版模板已含)。其中 23.2/23.3/23.4/23.15 的操作主体是 implementer,符合 CLAUDE.md §0 设计原则("角色专属规范进 skill 全文注入");23.11/23.13/23.14 是全角色铁律,摘要化风险比前者高,23.11 定为中风险。
2. 指针化时需同步改 implementer/reviewer skill description 里"共享核心(§6/§22/§5/§23/§8§14摘要/§18索引)在根 CLAUDE.md 自动注入"这句(§23 不再全量注入,改"§23 摘要注入+专属条目操作版见本 skill")。
3. §23.11 用户原话("全做。尤其是 d。...")全文零副本,指针化前先把原话补进 docs/conflict-overwrite-rootcause-2026-08-18.md 归档,防唯一事实源丢失(§23.8 双向咬合要求同步)。
4. 所有指针化/压缩均为"移动/压缩不删除",底层内容在原位置(skill/归档)原封,出问题可逆恢复(§5.3)。
