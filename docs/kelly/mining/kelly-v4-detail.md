## 1. 挖掘方法论

v4 引入 4 个新数据挖掘方法，各解决前几轮一个瓶颈：

### 1.1 Contrast Set Mining（对比集挖掘）

**是什么**：比较两个组（亏损组 vs 盈利组）的 itemset support 差异。指标 `growth rate = supp_loss / supp_gain`，>3 表示"亏损交易独占模式"（盈利笔中几乎不出现）。

**与关联规则 lift 的关系**：lift = 亏损偏斜倍数（亏损组内占比 vs 整体亏损率）；growth rate = 亏损独占性（亏损组占比 / 盈利组占比）。growth rate 高但 lift 未必高 = "亏损交易中常见但整体不一定常见"的细分模式。

**解决了什么**：v3 只用关联规则 lift，无法识别"亏损组独有但整体不常见"的细分模式。v4 用 growth rate 识别出 V4-C（3月+周三+辅关注+低分 ratio=27.54）等亏损独占标志，适合做 surgical toggle。

### 1.2 Emerging Pattern / JEP（涌现模式 / 跳跃涌现模式）

**是什么**：Emerging Pattern = growth rate > 1 的 itemset（从一个组到另一个组 support 增长）。Jumping EP (JEP) = 盈利组 support=0（亏损独有，盈利组完全不出现）。

**v4 应用**：ratio=999 即损盈=0（JEP）。V4-A（追关注+5月+概念+低价）和 V4-F（6月+周三+主关注+related）是典型 JEP--近年盈利交易中完全不出现这些组合。

**解决了什么**：v3 没有区分"有界比值"和"JEP 无界比值"，ratio=999 的标志被当作普通高比值处理。v4 明确标注 JEP 类，并要求 n>=100 + 逐年全正验证。JEP 的风险是样本小导致偶然无盈利笔，需 n>=100 + 逐年验证。

### 1.3 Closed Itemset 去冗余

**是什么**：Closed itemset = 没有超集与之 support 相同的频繁项集。在降亏语境下，一个 4-itemset 如果去掉某个条件后比值仍 >3 且净影响更高，则该条件冗余。

**v4 应用**：对 8 个 top 4-itemset 逐一尝试去掉每个条件，检查比值和净影响变化。关键发现：

| 标志 | 去掉条件 | n 变化 | 比值 | 净影响 | 结论 |
|------|---------|--------|------|--------|------|
| V4-C 3月+周三+辅关注+低分 | drop ts_bin=<50 | 114->366 | 27.54->7.84 | 59,868->112,532 | 低分条件冗余，覆盖翻 3 倍，比值仍 >3 |
| V4-E 1月+主关注+高价+低评级 | drop rating_dim=low | 114->132 | 11.27->10.11 | 39,613->40,753 | 低评级冗余 |
| V4-H 11月+低分+高价+追关注 | drop buyprice_bin=high | 102->822 | 32.02->3.48 | 32,777->143,841 | 高价冗余，覆盖暴增 8 倍 |
| V4-D 12月+周二+辅关注+低分 | drop ts_bin=<50 | 102->246 | 12.20->4.63 | 39,177->55,565 | 低分条件冗余 |

**解决了什么**：v3 未做去冗余，很多 4-itemset 的第 4 条件只是"锦上添花"（提升比值但减少覆盖）。实施时若直接用 4-itemset 会排除过少交易。Closed itemset 去冗余让实施版覆盖更大、净影响更高。

### 1.4 贪心组合优化（Greedy Toggle Selection）

**是什么**：从 930 个候选池中贪心选择 toggle（并集排除），每步选使净影响最大化且满足约束（比值 >3、损盈 <10%）的 toggle，直到无法改善。

**vs v3 组合方法**：v3 只做了 3 个预设组合（R7/R8/R10），人工拼凑组件。v4 贪心系统搜索 930 个候选的最优组合，15 步内找到净影响 +1.49M 的组合。

**解决了什么**：v3 人工拼凑 3 个组合无法达到 v4 贪心系统搜索的效果。Greedy-7/10/15 净影响是 v3 R10 的 1.49~2.20 倍，且 maxSh=0.28 强稳健。

### 方法论总结

| 方法 | v3 是否用 | v4 应用 | 解决的瓶颈 |
|------|----------|---------|-----------|
| 决策树 CART | ✓ | - | - |
| 子群发现 beam search | ✓ | - | - |
| 关联规则 2-itemset | ✓ | - | - |
| 多维交叉穷举（2-3 特征） | ✓ | 扩展到 4-itemset | 1502 个 4-itemset ratio>3 |
| **Contrast Set Mining** | ✗ | ✓ | v3 只用 lift，无法识别亏损独占模式 |
| **Emerging Pattern/JEP** | ✗ | ✓ | v3 未区分有界/无界比值 |
| **Closed Itemset 去冗余** | ✗ | ✓ | v3 未做去冗余，第 4 条件浪费覆盖 |
| **贪心组合优化** | ✗ | ✓ | v3 人工拼凑无法系统搜索最优组合 |

另外 v4 做了**特征等价去重**：验证 signal↔sig_dim、etf_dim↔track_tier、mkt_dim↔match_method 的等价关系后去重，从 v3 的 13 个特征（含冗余）减到 10 个非冗余可泛化特征（53 个 item），搜索空间更干净。

## 6. 过拟合风险评估

### 6.1 DeepSeek 已识别的 ⑦⑧ 过拟合模式

- ⑦ = n5（5月+低价，ratio 4.02）：**2026 年占全历史净影响 66%**，2021-2023 连续 3 年子集盈利。已标⚠️监控。
- ⑧ = n6（mid+5月，ratio 3.35）：**2026 年占全历史净影响 71%**，2021 大额子集盈利 -1.74 万。已标⚠️监控。
- **过拟合特征**：近年（尤其 2026）单年占比过高（>60%），早年有子集盈利年，说明标志不是全周期稳定亏损而是近年集中亏损。

### 6.2 v4 新标志过拟合风险分级

**强稳健（低风险，可默认 toggle）**：

**JEP 类标志（ratio=999）特殊风险**：
V4-A（n=156）和 V4-F（n=60）的 ratio=999 表示盈利组完全不出现此模式。JEP 的风险是"小样本偶然无盈利笔"vs"真实亏损独占模式"。V4-A 的 n=156 较充足 + 5 年全正，风险较低；V4-F 的 n=60 不足，风险较高。

### 6.3 5 月系标志的近年 shift（v3 警告，v4 确认）

v3 警告 5 月系 2021-2023 盈/2024-2026 亏 shift。v4 确认：
- V4-A/B/I/J 均 5 年全正（2020-2026），近年连亏，**shift 痕迹弱于 v3 的 N5/N6（⑦⑧）**
- Greedy 组合含 5 月 toggle（step 1/10），但 2021-2022 组合整体仍净正（maxSh=0.28），**5 月 shift 被其他 toggle 对冲**
- 完全避开 5 月的选项：V4-C（3月）+ V4-D（12月）+ v3 R8（3/11月）

### 6.4 结论

v4 新标志中，**Greedy 组合**通过多 toggle 并集分散了单年依赖（maxSh=0.28 vs ⑦⑧的 66%/71%），**不存在 ⑦⑧ 同类过拟合问题**。单标志中 V4-C 和 V4-B 风险最低。V4-F/V4-M/V4-G 过拟合风险较高，建议附监控。
