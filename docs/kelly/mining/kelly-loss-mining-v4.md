## 2. 方法论扩展（新文献/新算法应用记录）

### 2.1 Contrast Set Mining（对比集挖掘）

**原理**：比较两个组（亏损组 vs 盈利组）的 itemset support 差异。一个 itemset 如果在亏损组的 support 显著高于盈利组，则是"亏损特有模式"。

**指标**：
- `supp_loss` = itemset 在亏损交易中的 support
- `supp_gain` = itemset 在盈利交易中的 support
- **growth rate** = supp_loss / supp_gain（>1 = 亏损偏斜，>3 = 强亏损特有）

**与关联规则 lift 的关系**：lift = (supp_loss/N) / (整体亏损率) = 亏损偏斜倍数；growth rate = 亏损组 support / 盈利组 support = 亏损独占性。growth rate 高但 lift 未必高的 itemset = "亏损交易中常见但整体不一定常见"的细分模式。

**v4 应用**：对 1/2/3/4-itemset 计算 growth rate，筛选 growth>3 的亏损特有模式。发现 growth rate 和比值（Lift-1）高度相关但不完全同步--growth rate 高的标志更"亏损独占"（盈利笔极少），适合做 surgical toggle。

### 2.2 Emerging Pattern / Jumping Emerging Pattern（涌现模式）

**原理**：Emerging Pattern = growth rate > 1 的 itemset（从一个组到另一个组 support 增长）。Jumping EP (JEP) = 盈利组 support=0（亏损独有，盈利组完全不出现）。

**v4 应用**：识别 JEP 标志（ratio=999 即损盈=0 = 盈利组无此模式）。V4-A（追关注+5月+概念+低价）和 V4-F（6月+周三+主关注+related）是典型 JEP--近年盈利交易中完全不出现这些组合。JEP 的风险：样本小导致偶然无盈利笔，需 n≥100 + 逐年验证。

### 2.3 Closed Itemset 去冗余

**原理**：Closed itemset = 没有超集与之 support 相同的频繁项集。在降亏标志语境下，一个 4-itemset 如果去掉某个条件后比值仍 >3 且净影响更高，则该条件是冗余的。

**v4 应用**：对每个 top 4-itemset 标志，逐一尝试去掉每个条件，检查比值和净影响变化。关键发现：

| 标志 | 去掉条件 | n 变化 | 比值 | 净影响 | 结论 |
|------|---------|--------|------|--------|------|
| V4-C 3月+周三+辅关注+低分 | drop ts_bin=<50 | 114→366 | 27.54→7.84 | 59,868→112,532 | 低分条件冗余，去掉后覆盖翻 3 倍，比值仍 >3 |
| V4-E 1月+主关注+高价+低评级 | drop rating_dim=low | 114→132 | 11.27→10.11 | 39,613→40,753 | 低评级冗余 |
| V4-H 11月+低分+高价+追关注 | drop buyprice_bin=high | 102→822 | 32.02→3.48 | 32,777→143,841 | 高价冗余，去掉后覆盖暴增 8 倍 |
| V4-D 12月+周二+辅关注+低分 | drop ts_bin=<50 | 102→246 | 12.20→4.63 | 39,177→55,565 | 低分条件冗余 |

**启示**：很多 4-itemset 的第 4 个条件是"锦上添花"（提升比值但减少覆盖），实施时可去掉以增大覆盖和净影响。Closed itemset 去冗余是 v3 未做的方法论增量。

### 2.4 贪心组合优化（Greedy Toggle Selection）

**原理**：从候选池中贪心选择 toggle（并集排除），每步选使净影响最大化且满足约束（比值>3、损盈<10%）的 toggle，直到无法改善。

**v4 应用**：
- 候选池：930 个严格筛选的 ratio>2.5 标志
- 目标：最大化净影响（排除后总净利增加）
- 约束 1：组合整体比值 >3
- 约束 2：损盈 <10%（避免排除过多交易）
- 逐步选择，每步遍历剩余候选选最优

**vs v3 组合方法**：v3 只做了 3 个预设组合（R7/R8/R10），人工拼凑组件。v4 贪心系统搜索 930 个候选的最优组合，15 步内找到净影响 +1.49M 的组合。

## 7. 过拟合风险与方法局限

### 7.1 过拟合风险分级
- **强稳健（可默认 toggle）**：Greedy-7/10/15（maxSh=0.28，11/16 年净正）、V4-C（4 窗口极稳）、V4-B（6 年全正）、V4-D（5 年全正）
- **中稳定（附监控）**：V4-F（n=60 小）、V4-G（近年才转亏）、V4-K（有子集盈利年）、V4-M（只 3 年数据）
- **JEP 类标志（ratio=999）**：V4-A/V4-F 近年无盈利笔，比值虚高（损盈=0）。需 n≥100 + 逐年全正验证。近年无盈利笔可能是小样本偶然，也可能是真实亏损独占模式。

### 7.2 5 月系标志的近年 shift（v3 警告，v4 确认）
v3 警告 5 月系 2021-2023 盈/2024-2026 亏 shift。v4 确认：
- V4-A/V4-B/V4-I/V4-J 均 5 年全正（2020-2026），近年连亏，shift 痕迹弱于 v3 的 N5/N6
- Greedy 组合含 5 月 toggle（step 1/10），但 2021-2022 组合整体仍净正（maxSh=0.28），5 月 shift 被其他 toggle 对冲
- 完全避开 5 月的选项：V4-C（3月）+ V4-D（12月）+ v3 R8（3/11月）

### 7.3 方法局限
1. **贪心非全局最优**：贪心组合是局部最优，非穷举。但 930 候选的 C(930,15) 穷举不可行，贪心是合理近似。可用遗传算法/NSGA-II 进一步优化（未来方向）。
2. **无前向 walk-forward 验证**：仅历史回测，未模拟"排除后信号减少致仓位集中度变化"对 Kelly 仓位的影响。
3. **JEP 标志的比值无限大**：ratio=999（损盈=0）的标志，比值无界，难以和有界标志直接比较。用净影响和 maxSh 辅助判断。
4. **4-itemset 小样本**：4-itemset 的 n 多在 60-200，小样本过拟合风险高于 2-3 itemset。严格筛选（n≥100 + 4 窗口>2 + maxSh<0.65）缓解但未消除。
5. **Closed itemset 简化可能丢失信息**：去掉条件后覆盖增大但比值降低，是覆盖-比值 tradeoff。报告同时给出原版和简化版供选择。

### 7.4 已验证的方法/维度清单（充分性自证）
- **v3 已验证**：决策树（全特征+可泛化）、子群发现（beam search）、关联规则（2-itemset lift）、2-3 特征交叉穷举、跨年稳定性
- **v4 新验证**：
  - Contrast Set Mining（growth rate = supp_loss/supp_gain）：1/2/3/4-itemset
  - Emerging Pattern / JEP（盈利组 support=0）：识别 V4-A/V4-F 等
  - 4-itemset Apriori（从 3-itemset ratio>2 扩展）：1502 个 ratio>3
  - Closed Itemset 去冗余（逐一 drop 条件验证）：8 个 top 标志全部验证
  - 贪心组合优化（930 候选，15 步，约束 ratio>3 & sacr<10%）：Greedy-7/10/15
  - 特征等价去重（signal=sig_dim, etf_dim=track_tier 验证）
  - 新维度：6月/12月/9月/4月/全球指数/Q1-Q4 季度，全部纳入
- **未纳入（数据缺）**：market_state（MA60 多空，本版本无此字段）、买入前涨幅/波动率（需另接行情数据）、ETF 持仓重叠度（需另接持仓数据）

## 8. 未来方向（v5 可选）
