# 凯利回测降低亏损穷举模拟分析

> 生成日期：2026-08-09 ｜ 调研性质不commit ｜ 数据源：`signal_kelly_backtest.py` 修改版跑21组模拟 + `signal_kelly_trades.json` 亏损特征分析
> 信号固定（不改queries.py信号生成），仅回测层面加过滤条件

## 0. 摘要（核心结论先讲）

**穷举21组模拟条件，3条核心发现：**

1. **排除 buy_aux 信号是最有效的单条件过滤**——近5年 Mode A 总收益从 +356K 升至 +393K（+10%），亏损总额从 -1,065K 降至 -671K（-37%），且不牺牲牛市收益。buy_aux 是唯一净负收益信号类型（-33K 元），直接移除即增收。

2. **MA60 大盘择时 + 排除 buy_aux 是最佳平衡组合**——2022+2023 熊市亏损减少 70%（-108K -> -33K），总亏损减少 64%（-1,065K -> -386K），同时保留 98% 的总利润。胜率从 0.529 升至 0.558，盈亏比从 1.70 升至 1.93，最大回撤从 0.38% 降至 0.29%。

3. **止损（-3%/-5%/-7%）反效果**——54.2% 的止损触发是"误杀"（交易本会在10天内恢复），止损后总亏损反而增加 6%。10天固定持有期已天然限制亏损幅度，止损截断了恢复型交易。

**推荐实施排序：**
1. 排除 buy_aux（零成本增收，立即可做）
2. MA60 大盘择时仅 A 股类（熊市保护，已调研待实施）
3. 组合 1+2（最佳平衡）
4. Mode F（15天持有）替代 Mode A（全场多56%利润）

## 6. 实施建议

### 6.1 最小改动方案（P0：排除 buy_aux）

在 `signal_kelly_backtest.py` 的 `BUY_SIGNALS` 元组中移除 `"buy_aux"`：

```python
BUY_SIGNALS = ("buy", "buy_special", "buy_backup")  # 移除 buy_aux
```

或保留 buy_aux 在回测中但前端不展示 buy_aux 对应的象限（更安全，可对比）。

**预期效果：** 总收益 +10%，亏损减少 37%，不牺牲牛市收益。

### 6.2 完整方案（P0+P1+P2：排除aux + MA60择时 + Mode F）

1. 排除 buy_aux 信号（或降低其权重）
2. 加 MA60 大盘择时过滤（仅 A 股类 a/concept/industry，港股/全球不过滤）
