> 生成日期：2026-08-09 ｜ 只调研不改代码 ｜ 数据源：`signal_kelly_trades.json`（generated_at 2026-08-09 19:21，buy_amount=10000，7472 笔去重交易）+ `index_daily` 表 hs300 日频

## 0. 摘要

**问题**：当前回测所有买信号无差别进场（信号日收盘就买），2022/2023 熊市全亏（2022 胜率 0.465 均收 -0.698%，2023 胜率 0.422 均收 -0.557%），两年合计亏损 -112,957 元。

**推荐方案**：**沪深300 MA60 均线过滤，仅对 A 股类信号（market=a/concept/industry）生效**，港股/全球信号不过滤。

**效果**（近5年 2021-2026 回测验证）：
- 2022+2023 熊市亏损从 -112,957 元降至 -18,241 元（**减少 84%**），2022 年几乎持平（-18 元）
- 整体均收从 +0.617% 升至 +0.932%（+51%），盈亏比从 1.19 升至 1.33
- 过滤 41% 信号（3761/6415），保留高质量交易
- 港股/全球信号在 A 股熊市中仍可盈利（2022+2023 合计 +13,142 元），不过滤保留收益

### 3.2 关键发现

**发现 1：MA20 在熊市有 whipsaw（反复打脸）问题**

MA20 在 2022/2023 熊市中，剩余交易（多头信号）的表现反而更差：
- 2022：MA20 多头均收 -1.499% vs 无过滤 -0.698%（更差 2.1 倍）
- 2023：MA20 多头均收 -1.995% vs 无过滤 -0.557%（更差 3.6 倍）

**根因**：熊市中 hs300 频繁反弹上穿 MA20（假突破），此时信号触发买入，但反弹失败继续下跌。MA20 太灵敏，反而捕捉了最差的熊市反弹买入点。

**发现 2：MA60 在 2022 年几乎持平（最优熊市表现）**

- 2022：MA60 多头均收 -0.106%（154 笔），几乎零亏损 vs 无过滤 -0.698%（778 笔）
- MA60 更慢、更稳定，能有效识别熊市 regime，过滤 80% 的 2022 信号

**发现 3：MA60 在 2023 仍有泄漏**

- 2023：MA60 多头均收 -1.177%（267 笔），过滤 75% 信号，但剩余交易亏损
- 2023 是阴跌市，hs300 在 MA60 附近反复震荡，部分反弹突破 MA60 后仍失败

**发现 4：回撤过滤（DD<8%）能完全过滤 2022，但 2023 仍泄漏**

- DD<8% + MA20：2022 年 0 笔交易（完美过滤），但 2023 仍有 -1.663%
- 回撤过滤对急跌型熊市（2022）有效，对阴跌型（2023）效果有限

**发现 5：情绪分/市场宽度单独效果差**

- a_sentiment>=30：过滤仅 7%，均收 -0.257%（比无过滤更差）
- sentiment_hs300>=50：均收 -0.320%（更差）
- a_ma_bullish>=3：均收 -0.265%（更差）
- 情绪分是均值回归指标（低=恐慌=买入机会），不适合做趋势过滤

**发现 6：双均线（MA20+MA60）整体最优但熊市 whipsaw**

- 整体均收 +1.191%（最高），盈亏比 1.47（最高）
- 但 2022 均收 -1.156%（比 MA60 单线 -0.106% 差 10 倍），2023 均收 -1.409%
- 双均线要求更严格（两个都多头才进场），过滤掉更多信号，但允许通过的熊市反弹交易亏损更重

## 4. 推荐方案

### 4.1 方案选择

**推荐：MA60 多头过滤，仅对 A 股类信号（market=a/concept/industry）生效**

| 维度 | 选择 | 理由 |
|------|------|------|
| 均线 | MA60（非 MA20） | MA20 熊市 whipsaw 严重；MA60 在 2022 年几乎持平 |
| 范围 | 仅 A 股类（a/concept/industry） | 港股/全球与 hs300 不同步，熊市仍可盈利 |
| 规则 | close > MA60 = 多头进场 | 简单单条件，易实现易理解 |
| 空头处理 | 跳过不买（不做空） | 信号策略本质做多，空头不进场即足够 |

### 4.2 备选方案

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| MA60 全部过滤 | 最简单（不需分类） | 过滤掉盈利的港股/全球信号 | 追求极简实现 |
| MA20+MA60 双多 | 整体均收最高 +1.191% | 熊市 whipsaw，2022 均收 -1.156% | 追求最大收益能忍受熊市波动 |
| MA60+DD<8% | 2022 完全过滤（0 笔） | 2023 仍泄漏，2024 收益降低 | 追求极端熊市保护 |

### 4.3 不推荐的方案

- **MA20 单线**：熊市 whipsaw 致剩余交易更差（2022 -1.499%, 2023 -1.995%）
- **情绪分过滤**：情绪分是均值回归指标，不适合趋势过滤，效果比无过滤更差
- **市场宽度过滤**：a_ma_bullish 是离散计数（0-5），粒度粗，效果差
- **趋势涨跌过滤**：20日/60日涨跌方向效果不如均线（均线更稳定）

## 5. 实施方案（具体改动点）

### 5.1 新增函数

```python
# ── 大盘择时 ──────────────────────────────────────────────────────────────────
MARKET_FILTER_MA_WINDOW = 60  # MA60 均线窗口
# A 股类 market 标签（需大盘择时过滤的）
A_STOCK_MARKETS = {"a", "concept", "industry"}

def _load_market_state(conn):
    """加载沪深300日频, 计算 MA60, 返回 {date: True(多头)/False(空头)}。

    数据源: index_daily 表 index_id='hs300'。
   多头定义: 当日收盘价 > MA60。
    用 bisect 查找信号日最近的有 MA60 的交易日。
    """
    rows = conn.execute(
        "SELECT date, close FROM index_daily WHERE index_id='hs300' "
        "AND close IS NOT NULL ORDER BY date"
    ).fetchall()
    if not rows:
        print("  ⚠ hs300 数据为空, 大盘择时过滤不生效", file=sys.stderr)
        return {}, []

    dates = [r[0] for r in rows]
    closes = [r[1] for r in rows]

    # 计算 MA60
    ma_window = MARKET_FILTER_MA_WINDOW
    state = {}  # {date: True/False}
    for i in range(ma_window - 1, len(dates)):
        ma = sum(closes[i - ma_window + 1 : i + 1]) / ma_window
        state[dates[i]] = closes[i] > ma

    return state, dates


def _is_market_bull(signal_date, market_state, market_dates):
    """判断信号日的大盘状态。查找 <= signal_date 的最近有 MA60 的交易日。"""
    if not market_state:
        return True  # 无数据时默认允许(不过滤)
    import bisect
    idx = bisect.bisect_right(market_dates, signal_date) - 1
    while idx >= 0:
        d = market_dates[idx]
        if d in market_state:
            return market_state[d]
        idx -= 1
    return True  # 信号日早于 MA60 可用范围, 默认允许
```

## 7. 注意事项

### 7.1 whipsaw 风险

MA60 在 2023 年阴跌市中仍有泄漏（均收 -1.177%），因为 hs300 在 MA60 附近反复震荡产生假突破。**这是均线类过滤的固有限制**，无法完全消除。如需进一步减少，可叠加 DD<8% 回撤过滤，但会牺牲牛市交易机会。

### 7.2 重跑影响

- 加择时过滤后需**重跑回测**（`python3 scripts/signal_kelly_backtest.py`），因为过滤改变了哪些信号进场
- trades 文件会重新生成，信号笔数减少约 41%
- 前端 lab.js 如果不新增 timed 象限则无需改；如果新增则需改 groups 数组
- 算法公示文案需同步更新（CLAUDE.md §21）：在策略实验室算法说明中补"A 股类信号在沪深300 MA60 空头时不进场"

### 7.3 数据依赖

- hs300 日频数据由现有 `update_all` 定时任务采集（index_daily 表），无需新增采集
- MA60 计算 ~60 行代码，运行时几毫秒，不影响回测性能
- 如 hs300 数据缺失（极少数情况），`_is_market_bull` 默认返回 True（不过滤），安全降级

### 7.4 港股/全球信号不过滤的理由

| 大类 | 2022+2023 无过滤总元 | 理由 |
|------|---------------------|------|
| 港股(hk) | +3,890 | 恒生指数与 hs300 走势不同步，A 股熊市时港股可能反弹 |
| 全球(global) | +9,252 | 美股/欧股与 A 股相关性低，独立行情 |

如需对港股/全球也加择时，应分别用 HSI/SPX 的 MA60，但增加复杂度且样本量小（hk 177 笔/5y，global 590 笔/5y），收益有限。建议后续按需扩展。
