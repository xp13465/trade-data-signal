## 4. 诚实标注

1. **G 玩法 b0 口径负贡献 -2,256,但这是口径依赖的**:
   - G(b0,保守强平0利)= -2,256 / -1.74pp;G(b1,乐观线性)= +11,755 / +9.04pp;真实强平盈亏在区间内,方向不确定。

   - **不把 K2C5 当 G 玩法的优化键**(与 reconcile 报告一致)。
2. **I 模式轻微负贡献 -1,365 / -0.91pp**:I 是「满仓不买@15万」长持玩法,K2C5 剔除港股追涨后 I 净利略降。§3.2 显示 I 方向随核心3子集摆动(±7,000 内),属路径噪声而非稳定规律。I 的 8键合计仍 +137,708(正),不影响基础5定名。
3. **H 模式 8键非 16 组合最优**(最优=0+k2 +94,153,8键 +89,355):根因是核心3键对 H 固有负贡献(r7 -1,828 / aux -13,060 / g15 -5,354,见 §3.3),**这是穷举v2 已有的 v1.0.0 基准属性,不是 K2C5 引入的**。K2C5 对 H 在所有子集下都是正贡献(+6,429~+8,617)。
4. **G 玩法 8键非 16 组合最优**(最优=r7 单键 +226,328):G 玩法对核心3键天然敏感(r7 单键 +5,353 正、g15 单键 -12,023 负、aux 单键 -9,436 负)。8键全开 G +201,339 仍是正,且 y1 前向样本 8键 G 高于 7键。**若用户以 G 玩法为核心,应单独调 G 档(如只开 r7),但那是 v1.0.0 基准已决定的 A/F 主推定位,不是本报告推翻的范围**。
