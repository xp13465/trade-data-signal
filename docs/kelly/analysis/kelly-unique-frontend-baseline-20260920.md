## 6. 说明与口径注记

- **全信号宽表 ≠ 「最后结果」三档表**: 宽表按模式(A~J, 含 G/H/I)逐行统计该模式全部信号笔, 样本是「该模式的信号笔数」(去重后); 三档表是 G/H/I 三档最终汇总(净利 +146,718 等)。两者展示位不同、口径不同, 改造后各自 diff 空即可。
- **G 行「⚠稳定性存疑」标注**: G/I 模式含「P≤3d」长线管位, 样本数较少(29/45), 页面自动加稳定性警示, 属现有行为, 非本次改造引入。
- **基线只证「数值不变」, 不证「顺序不变」**: 方案 §四.1-3 允许新解析器按 base 遍历序直建 pool(旧按 qk 遍历序), 行顺序差异是预期的; 页面表格若按模式分组展示, 顺序由前端排序逻辑决定, 属 Phase B/C 消费逻辑范畴, 本基线如实记录改造前顺序。
