## 2. 诚实标注(口径差异,不选择性隐瞒)

- **K1 档展示口径**:lab.js ratio/tip 取 ALL9 合计 K1(减亏2.88%/损盈0.63%/比值4.55),因为页面默认 K 档 = K1(2026-08-14 #BC 由 K3 改 1,§5.4 基准组合 K=1)。
- **K2 档不取**:K2 档损盈 -0.03%(减亏 3.04%)——K2 砍量更多对盈利有轻微负影响,比值 999 是「损盈≈0」的特例,不代表"高性价比",故不取不公示为避免误导(与其他键 K2 档口径也不可比性弱)。若用户要 K2 档可回测脚本章节看原始数。
- **净Δ 口径差异**:本脚本单键「standalone on/off」净Δ K1 = -56,317(单独看单键会减净利),与 `kelly-k2c5-exhaust-interaction.md` 的全键组合「去K2C5损失=+41,445」(即打开 K2C5 相对全键组合是增益)口径不同——前者是「单键独立开关空filter基准」,后者是「在全键基础上加/去 K2C5 的边际」。两者不矛盾:K2C5 的价值体现在与基础5/核心3其他键**组合共振**(16组合全扫全局最优),而非 standalone 单键减亏净利。页面上 ratio 用 standalone 减亏比值(与其他键同口径横向可比),组合收益增益看穷举交互报告。
- **K3 诚实标注**:比值 1.29(<2)与其默认关结论自洽;K3 仍默认关,补实测值仅告别「待实测」占位(不编造数字),不改变默认关。
