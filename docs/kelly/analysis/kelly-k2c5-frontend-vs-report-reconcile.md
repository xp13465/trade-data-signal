# K2C5 toggle 前端 vs 报告 §7 口径对账(2026-08-15)

## 结论速览

**前端 K2C5 toggle 与报告 §7 用的是同一套 P3d 强平仿真(都是「过滤 K2C5 交易 → 重跑完整仿真」),不是"简单剔除"。唯一分歧 = 强平利润实现模型参数:b0(保守,强平记 0 利) vs b1(乐观,强平按持有时间线性实现利润)。**

- **报告 §7 = b0 口径**(v1.0.0 权威基准):G 基线 +205,746(158.27%),K2C5 剔除 all G Δ **-2,256**、I Δ -1,365
- **前端 GIH on 显示 = b1 口径**:G 基线 +237,952(183.04%),K2C5 剔除 all G Δ **+11,779**、I Δ -1,365
- 用户页面数字精确匹配 b1(差 ±1,247 为数据批差 02:38→21:14);报告 §7 精确匹配 b0
- **其他 8 模式(A-F/H/I)两口径逐位一致**(A-F 无强平、H/I hold_cap 无强平,强平不存在 → b0=b1),**只有 G 有强平路径**,故只有 G 在 b0/b1 下分裂——完美解释「页面其他 8 模式=报告,仅 G 不同」

**谁对谁错**:都不是"错",是**口径不一致**——报告/toggle tip 用 b0 保守,页面卡片用 b1 乐观。真实强平盈亏不可知,在区间 [b0, b1] 内(报告同款声明见 `lab.js:7768`「真实强平盈亏不可知(b0 0利 保守 / b1 按持有时间线性 乐观), 真实值在区间, 不把 b1 当承诺」)。

## 谁对谁错 / 用户该信哪个

1. **两个口径都"对",但语义不同**:
   - **b0(报告 §7)= 保守下限**:强平按 0 利兑现,低估真实收益。K2C5 对 G 显示 -2,256(剔除有害)
   - **b1(前端 GIH on)= 乐观上限**:强平按持有时间线性兑现,高估真实收益。K2C5 对 G 显示 +11,779(剔除有利)
   - 真实值在区间 **[-2,256, +11,779] 之间,K2C5 对可操作 G 的方向不确定**(报告 §7.5 已证:按年正负交织,是路径噪声,非稳定规律)
2. **稳定结论(两口径一致,可放心信)**:
   - K2C5 剔除对 **A/F/H/I 短持全正贡献**(all A+7,384/F+4,458/H+7,840,两口径同值)
   - I 的 -1,365 两口径一致(hold_cap 无强平)
3. **对 G 玩法**:不能因为页面 b1 显示 +11,779 就认为 K2C5 对 G 有利;也不能只看报告 b0 -2,256 就断定有害。**真实在区间,方向不确定**,不建议把 K2C5 当 G 玩法的优化键
4. **本次矛盾的直接原因**:前端 GIH on 卡片/toggle 对比显示 **b1 乐观值**,而 toggle tip 与报告用 **b0 保守值**,两个口径并存未标注,用户看到的数字(b1)与文案结论(b0)打架
