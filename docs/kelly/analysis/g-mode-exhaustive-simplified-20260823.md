## 一、结论速览(必答三问,先给答案)

1. **变了,而且「最佳组合」依交易方式分裂(交互效应)**——这是本轮最重要的机制发现:
   - **现行强平换仓型(P3D)下大池占优**:13万档排序 = RAW无过滤 +209,996(但 200 次操作/年,不可接受)> **9键 +191,108 > 8键 +184,715** ≈ B +184,653 > A > NEW14 > C。强平提供了周转,信号量=原料,过滤越强越吃亏;
   - **极简躺平型(V2)下强过滤占优**:13万档排序 = **NEW14 +139,891 第一**(回撤也最浅、近1年也第一)> C +132,899 > A +131,299 > 9键 > 8键 > B > RAW 垫底。仓位稀缺时质量>数量;
   - 与 mine25 §11(cap20 口径 NEW 第一)、E24(最优 toggle 组合依卖出模式分裂)互为印证:**没有脱离交易方式的「最佳过滤」,两者必须配套选**。
2. **极简法 vs 现行推荐的代价(13万档)**:现行推荐(8键+P3D 强平)= +184,715 / 2,239 次操作(143.7 次/年)。换极简:
   - 同过滤(8键+V2):+125,542,**损失 -59,173(-32.0%)**,操作降到 535(省 109.3 次/年);
   - **换 NEW14 过滤再躺平(推荐甜点位)**:+139,891,**损失 -44,824(-24.3%)**,操作降到 411(**省 117.2 次/年**)——直觉化:**每年少做约 117 次操作,15.6 年合计少赚约 4.5 万(年均 -2,873 元),平均每省一次操作约值 24.5 元**;且回撤不恶化(-12,561 vs -11,608),近1年反而强近 4 倍(+12,052 vs +3,187);
3. **甜点位存在**:**V2 回补 + NEW14 过滤 + 13万(cap13)**=「够简单且损失可容忍」;若想更贴现行收益还有中间档 **NEW14+P3D+13万 = +169,722(只差 -8.1%),操作仍省 62%**,代价是保留每日盯容量+强平的复杂度。叠加口径变体 **V2+(NEW14叠8键)+13万 = +142,390、回撤 -6,622 全场最浅级**,比独立口径更强,是躺平族的实质最优点(§八)。

## 四、口径定义

- **三种手法(同一重放层参数化,不另写引擎;自检断言 V2==mine25.replay_cap 逐位等值)**:
  - **p3d现行**:容量满时强平「≤3 日历天年轻仓中买日最早者」,无年轻仓 FIFO 最老,b0 记 0 利(逐位对齐 kelly_opg_engine.p3d_cap ↔ lab.js _kellyAihlineP3dCap 逻辑);
  - **v2回补(用户本意主口径)**:满仓跳过该日信号不买,自然卖出释放后才可再买,无任何主动换仓/强平/择时;
  - **v1一轮(附录对照)**:累计买入达 cap 后永不再买,卖出照常,资金沉淀。
- **资金档映射**:每笔固定本金 PRIN=10,000 元,资金档 N 万 = 并发上限 cap=N 笔(峰值占用≤N 万,占用=本金口径非市值);E23 支撑 K=1 等价性。
- **过滤 8 种**:RAW无过滤 / P0_8键(v1.1.2 默认) / P1_9键 / A_on9 / B_on9 / C_on9 / NEW14 / NEW18(均 K1 补位选信号;NEW14/NEW18 为独立重构口径=原始模式池+黑名单,mode A 权威锚点已验)。
- **矩阵**:8 过滤 × {p3d, v2, v1} × cap{10, 13, 20, 50} + nocap 对照 = 152 个统计格。
- 输出列:已实现/未实现(MTM)/合计、预算收益率、买/自然卖/强平/跳过计数、操作次数(总与年均)、峰持/占用、胜率、mdd 两口径(谷日/恢复日)、按年分解、压力窗(4 熊市+2026年2-3月)、近1年窗。
