## 3. 第三步：社区亏损交易单识别方法调研

**3 次 WebSearch 结果**（按可落地度整理）：

| 方法 | 社区要点 | 本项目落地情况 |
|---|---|---|
| **Trading journal 复盘** | 按 setup/session/方向分段统计；3 类连亏分类（假信号/情绪/大环境）；复仇交易检测（同方向连续亏损后是否加重）；赢家持有时间 vs 输家；expectancy 期望值 | **已落地**：分段亏损统计（本报告全部）+ market_state/rating/signal 交叉即"按维度分段" |
| **Regime-split 回测（MRP / Minimum Regime Performance）** | 信号-收益是 regime 条件依赖，不在某 regime 达标则降级/剔除；策略衰减检测（滚动窗口 / CUSUM / MAE-MFE drift） | **regime-split 已落地**：trades.json 自带 market_state 字段做交叉维度（§2.4，空头低分段反而最好）。**滚动窗口/CUSUM/MAE-MFE 不可测**（需逐日 mark-to-market 价格路径，trades 只有买入/卖出两端价） |
| **TradingAgents 反射系统（Reflector）** | 因子分析 + 纠正动作（撤单/重定价/加 filter） | 已落地为"剔除验证"范式（本报告 §2.3），纠正动作用于回测验证 |
| **Prospect theory（28.5M 交易实证）** | 亏损交易者共性 r<1 / s<1 / u<1（赚多次小钱、一次大亏）；**胜率单独是差预测器** | 印证本项目"看净利+回撤而非只看胜率"口径；亏损单识别应看"单笔亏损额分布"而非胜率 |

**可借鉴但标注不可测**：信号衰减滚动窗口 / CUSUM 突变检测 / MAE-MFE 漂移——都需持有期内逐日价格路径数据，当前 trades 只有买入/卖出两端价，**需新数据采集（每日快照）才能做，本报告不承诺**。

## 4. 结论（假设不成立，诚实标注）

1. **主假设不成立**：v1.0.0 基准下不存在"某 track_score 分段亏损概率显著大于其他段"的稳定黑洞。信号层亏损概率在 27-45% 窄幅波动；组合层最差段 G/A/F 不重叠；剔除任何段 G 全部负向、A/F 仅噪声级微正。
2. **弱规律（诚实标注，不做主推）**：分位数 10 段 60.4-65.1 窄段亏概率 45.4% 信号层最高；60.4-66.4×mid 信号层唯一负净格（n=178）。**但**剔除验证全负/微正 + 按年无一致性 + n 小 → **过拟合风险高，不构成可操作信号**。若未来做更细挖掘，建议先用"该段按年是否稳定为负"过滤，再考虑剔除。
3. **根因**：track_score 是"跟踪紧密程度"维度，与"信号盈利能力"是**无关维度**（v1 §4.6/v2 §2.5 结论被本报告完整验证）。组合层高分段略高亏损概率是 **topK 选择效应**（高分段选入多）+ 维度错配。
4. **对 v1.0.0 基准结论无变更**：本报告不改变任何已上线默认组合，纯调研验证。

### 诚实标注清单
- 数据 generated_at 2026-08-15 19:08，与旧报告（08-13/08-09）绝对值有微差，属预期非错误。
- 每日池资金重分配效应：剔除某段后剩余信号每笔金额变大，导致"剔除验证"天然偏向"剔除任何段都降总净"——但收益率(Δ)也全负，结论稳健。
- n<30 的格子（track_tier×strong n=16、rating×high 各 n=14-23）小样本，不采信。
- 卡方检验仅信号层显著（分位数10段 chi2=61.5），组合层 n 小不单独卡方。
- 滚动窗口/CUSUM/MAE-MFE 衰减检测需逐日价格路径数据，**本报告不可测**，留作未来数据增强方向。
