## 4. 诚实标注

- **I 是「除 G 外」唯一的负贡献**:-1,365 净利 / -0.91pp,虽小但方向为负。用户认知①对 A-F/H 7 个模式成立,对 I 不成立;除 G 外 8 模式合计 Δ 净利仍 +43,701(正)。
- **G 双口径待定**:b0(保守,强平记 0 利)= -2,256 / -1.74pp;b1(乐观,强平线性实现)= +11,755 / +9.04pp。真实强平盈亏不可知,方向在区间内不确定——**不把 K2C5 当 G 玩法的优化键**(与 reconcile 报告 §「谁对谁错」一致)。
- **维度 2 的象限 Δ 是「全局重算后的净效应」,不只是该象限被剔除交易的直接贡献**:K2C5 剔除会通过全局 positionCap(K=1 kept 集合)+ 每日资金池等分金额传导到所有象限。例:市场-概念(-8,749)/市场-A股(-2,924)/市场-全球(-438)/ETF-近似(-4,059)是 down 方向,机制 = 某些天原来 kept 的是 K2C5,剔除后换成次优交易,被挤进 kept 的次优交易整体偏亏,拖累这些象限净利。**这是全局重算的正确行为(与前端 K2C5 toggle 一致),不是 bug**。
- **无 K2C5 交集、Δ=0 的象限**(评级-高/ETF-强跟踪/ETF-有跟踪/信号-主/信号-辅):这些象限的交易与 K2C5 交易从不在同一天竞争 K=1 名额,剔除前后 kept 判定与资金池完全不变。**其中 ETF-有跟踪卡基线就是 7 行负,但 K2C5 剔除救不了它**(它是另一个亏损源)。
- **评级-低 down 的 1 行**:见数据文件 `dim2['rating_low']['delta_b0']`,为传导造成的单行小负,不影响该卡整体 +36,403。
- **收益率基准口径**:峰值资金收益率 = 最终盈亏 / 峰值同时持仓资金 × 100。**不是** 单笔本金收益率或年化。E 模式收益率 Δ +13.09pp 大于净利 Δ 的原因是 E 峰持仓仅 5万(分母小),H 同理(峰仓 7万)。
- **数据版本**:基于 `static-site/data/signal_kelly_trades.json` 2026-08-15 21:14 批(generated_at),与 reconcile 报告同批;若换数据批,绝对数字需重跑(方向/口径结论不受影响)。
