# accum_nav 历史缺价「实地重采可补性」验证报告(2026-09-06,researcher 全量实测)

> 结论一句话:**2081 条历史缺价中 82.6%(1718 条)东财源全史本来就有,一次历史回填即可补回——「补不出价格」的判断不成立,原因是管道只增量补近 30 天、从不历史回填;剩下 17.4%(363 条)源头确实没有,其中 97% 是跨境 QDII 的海外休市/净值时滞日(补了反而造假),真正境内源缺只有 2 条。**

## 1. 管道机制(为什么历史缺价不补)

`app/collector/etf_national_team.py`:

- L1983 `fetch_accum_nav_series` 调 `ak.fund_open_fund_info_em(symbol=code, indicator="累计净值走势")`,返回**全史序列** `{YYYYMMDD: 累计净值}`(已复权)。
- L2065 `update_accum_nav` 增量扫描 **`WHERE date >= 今天-30天 AND accum_nav IS NULL`**(L2076-2081)→ **只补近 30 天的 NULL 行**,历史缺价永远不进扫描范围。
- 历史唯一一次全量回填是 2026-08-08 一次性回填至 20260807(L1956 注释),此后只增量没回填。
- **结论:管道「只增量不回填」= 历史 2081 条缺价注定永远留着**;原报告把「源缺失」当主因判断有偏,真因是「管道只增量不回填」,82.6% 源上有数据。

### 2.4 源缺 = 海外休市/时滞日(结构性,补了才是造假)

抽查源缺日,A 股当日覆盖数 39-1476(在交易),但**海外市场休市**:

- 12/25(圣诞,港股/美股休市):20151225/20171225/20181225/20191225/20201225/20241225/20251225 等 **9 个 12/25 全部命中缺价**
- 11 月下旬(感恩节带,美股休市):20161124/20171123/20181122/20191128/20201126/20211125 **全部命中**
- 20150403 耶稣受难日、20150525 阵亡将士纪念日、20150928、20160118 马丁路德金日等——全为海外休市/节假日
- 跨境净值规律:海外收盘晚于 A 股,当日有场内价但基金公司当日不公布净值 → 源当日无净值属**正常现象**,不是缺价事故

### 2.5 境内 2 条源缺(两源交叉验证确认真缺)

512560 20210315、512660 20190410:东财源 + **天天基金源(第二独立数据源)** 均无该日净值 → 真源缺(可能历史停牌/数据源本身缺),占比 2/2081 = 0.1%,可忽略。

## 3. 与缺价分析报告(accum-nav-gap-analysis-20260906)的对照

原报告「根因 60% 历史数据源缺失」判断**部分修正**:

- 「完全无行 1299 段」形态 → 本次实测大部分**源有值**(1718 可补),原判断「源缺失」实为「管道没回填」,方向修正
- 「单日采集漏采 30%」→ 多数也源有值,重采可补,成立
- 「QDII T+1 时滞 10%」→ 确认 17.4% 源缺中 97% 是跨境休市/时滞,成立且占比上调

**结论:原报告推荐 B+D(不补+告警)需升级为「历史一次性回填 + 告警」——因为 82.6% 可零外源补回,成本低、不引入脏数据(源本身是真值),不是插值污染。**

## 4. 回填可行性方案(若实施)

- **脚本**:写一次性回填脚本,复用 `fetch_accum_nav_series` + `_upsert_daily`(可直接 import etf_national_team.py 的函数),遍历 2081 条缺价日调源接口补齐;对源缺 363 条(尤其跨境休市日)跳过,不写。
- **工作量**:154 只全测耗时 ~6 分钟(0.5s/只限流),回填一次全量约 10 分钟内可完成。
- **风险**:极小。补的是源真实值(与回测加载口径一致,已复权),不引入插值假价;跨境源缺日跳过不写,不污染。
- **口径注意**:只回填 `accum_nav IS NULL` 的行;已有值不动。

## 5. 建议

1. **历史一次性回填(新)**:82.6% 可零外源补回,直接清掉 1718 条历史缺价 → 前端 GHI 弹窗/净资产曲线历史缺价大幅减少,页面「缺价」红字只剩真缺(跨境休市日/2 条境内)。
