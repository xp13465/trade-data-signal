## 一、一句话结论

**用户的想法在数据上成立,而且最优做法就是"兜底版分批挂单":分 N 单挂次日开盘-1% 限价,没触达的按开盘价兜底买,预算 1w 用满。** 每日池 G 模式 K=1 时净利从"次日开盘直接买"的 +80.0 万提升到 +86.1 万(Δ+6.1 万),收益率 53.17%(比次日开盘 +3.8pt),均价稳定在 -0.37%。**N 越大买到概率越高(37%→54%),但净利略降,所以 K=1/N=1 数据最优,K=2/N=2 是平衡点。** 深度 -1% 是最优挂单价,挂太深(-2%)触达率骤降反而亏。

## 三、操作标准 SOP(次日分批挂单玩法)

### 3.1 玩法定义
- **时机**:前一日出信号 → 次日开盘前挂限价单。
- **挂单价**:次日开盘价 × 0.99(开盘 -1%)。若无法预知开盘价,可用"昨日收盘 × (1+预期平开幅度) × 0.99"近似,或集合竞价后按开盘价立即挂 -1%。
- **单数 N**:= K(当日保留的 top-K 信号数)。**N=K 每单金额 = 10000/N**。
- **成交规则(兜底版)**:盘中若最低价 ≤ 限价 → 按限价成交;若全天未触达 → 尾盘按开盘价补买(或次日开盘补)。**预算 1w 必须用满**。
- **买够 1w**:初始 N 单每单预算 10000/N;未触达的额度不浪费,优先补当日 top-K 剩余品种(池内补),不要降级到 top-K 之外。

### 3.2 推荐参数(数据最优)
| 参数 | 推荐值 | 依据 |
|---|---|---|
| K 档 | **K=1 最优, K=2 平衡** | K1 净+86.1万/收益53.17%; K2 净+75.2万/收益45.71% |
| 挂单深度 | **-1%** | 深度敏感性 -1% 净利最大(见 §6.2) |
| 单数 N | **N=K**(K=1 就 1 单,K=2 就 2 单) | N=K 预算利用率与触达率平衡最好 |
| 成交规则 | **兜底版**(未触达按开盘买,预算用满) | 严格版资金用不满净利腰斩(见 §6.3) |
| 补单来源 | **池内补**(当日 top-K 剩余) | 降级补净利大降(见 §6.4) |
| 资金口径 | 每日池 1w/日等分 | 每笔固定 1 万峰值 296-411 万=不可操作杠杆(教训 L32) |

### 3.3 完整操作步骤(每日)
1. 前一日收盘后拿到当日 top-K 信号(按 track_score→rating→signal 类型→buy_date 排序,取前 K)。
2. 次日上午:每信号挂 1 单"开盘价 -1%"限价买单,每单金额 = 10000 / K。
3. 盘中:触达的按限价成交;未触达的挂单尾盘前不撤。
4. 收盘前:未触达的额度,按剩余可买品种(当日 top-K 里还没买到的)的现价补买,把 1w 预算用满。
5. 卖出侧:完全沿用现有信号卖出逻辑(G 模式按后续 sell/sell_stop_loss 信号;A-F 按记录口径二阶近似),**买入方式改动不影响卖出**。

### 3.4 当日 vs 次日两套操作建议(供首页"推荐参考说明"补次日建议用)

**当日玩法(原有)**:信号当日收盘买,收益最高但承担当日竞价/滑点。

**次日玩法(本报告,数据更稳)**:
- 次日开盘直接买:净利比收盘买仅低 0.01%(每日池口径,几乎无成本),胜率反升 0.1-0.4pt——**不想麻烦就次日开盘无脑买,几乎不输**。
- 次日分批挂单(本报告主推):分 N 单挂开盘-1% 兜底买,多赚 6 万(Δ+5.9~6.1 万),均价 -0.37%,**比开盘直接买更优且不用盯盘等最低点**。
- 操作话术建议:"次日集合竞价后按开盘价挂 -1% 限价,没成交的尾盘按现价补,把当日 1w 预算买满"。

## 七、诚实标注(挂单模型假设)

1. **触达判定用日线 low**:只要"当日最低 ≤ 限价"即认定按限价成交。真实盘口可能因瞬间下探/集合竞价/流动性不足导致部分触达单未成交,或成交价略差。真实触达率可能略低于数据(37-54%)。
2. **兜底按开盘价买入**假设未触达单尾盘/次日能以开盘价补回;真实尾盘补买可能有滑点(滑点量化见底子报告 §5.2:每笔 -1.6~-3.0 元,对 1 万单 = -0.016%~-0.030%)。
3. **A-F 模式为卖出二阶近似**:固定持有/止盈模式保持记录卖出日/卖出价不变。真实"固定 N 天"会因买入晚 1 天而卖出晚 1 天(本报告卖早 1 天);止盈模式买入价更高时止盈触发更晚(本报告按记录的早止盈=对次日口径略乐观)。量级二阶,不影响结论。G/H/I(信号驱动卖出)精确。
4. **数据版本差异**:本报告用 8-15 00:45 重新生成的 signal_kelly_trades.json(G 模式基笔 7598)。底子报告(kelly-nextday-open-backtest.md)用旧数据(7414),故 K=1 次日开盘基准从 +784,576 变为 +800,486、兜底从 +84.5 万/52.81% 变为 +86.1 万/53.17%。**新数据下"兜底多赚约 6 万"的结论不变,绝对数字以本报告为准**。
5. **伪跳空剔除**:2 笔份额折算伪跳空(512560 军工ETF 2021-11-15、159739 云计算ETF 2026-08-03)已剔除,否则虚增次日收益 +17,605 元。
6. **收益率口径**:净/峰值持仓,峰值持仓是分母,买入晚 1 天使并发峰值略降的"收益提升"部分是机械效应(底子报告 §1.3),但本报告 Δ 净利是绝对收益,不受此影响。
7. **没有考虑卖出侧的限价优化**:本报告只优化买入侧。卖出侧同样有"次日开盘 vs 盘中限价"的空间(卖出侧回测见其它报告),本报告买入侧结论独立成立。
