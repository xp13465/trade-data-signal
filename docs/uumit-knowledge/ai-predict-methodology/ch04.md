# 第 4 章 多角色辩论:6 角色编排怎么工作

> 一句话定位:AI 内部不是一个人,是一支团队。

## 白话:什么是「多角色辩论」?

早期 AI 预测是**单 prompt 一次调用**——把全部数据揉进一个 system+user,一次让模型输出 4 段短文。缺点:数据大杂烩、每维度浅尝辄止、无多视角对抗、容易受模型立场影响、不可溯源。用户看请求日志后质疑:"不是多 agent 辩论了么?"

于是参考 **TradingAgents-CN** 的多角色协作框架,改成**轻量自研 6 角色编排**(不自引第三方依赖):

```
┌─ ①技术面分析师(并行) ─┐
├─ ②资金面分析师(并行) ─┤
读数据(load_data 拆域) → ├─ ③情绪面分析师(并行) ─┼─► ⑤研究员(多空辩论,串行) ─► ⑥主编(组装+meta+合规) ─► daily_brief.json
└─ ④风控(并行) ──────────┘
```

**每角色只喂自己的数据域**(缩小数据域控幻觉):技术面只喂指数/信号/胜率,资金面只喂主力/两融/期货持仓,情绪面只喂恐贪/情绪分/冰点,风控只喂 alert dims/波动率/量价背离。四角色并行 → 研究员把四份论据整理成「多头论据 / 空头论据 / 倾向+置信度」,允许"震荡/看不清" → 主编组装 4 段输出 + meta 断言 + 指令词合规校验。

**不引入交易员/组合经理角色**(合规红线):输出只到「关注/观察/风险」,不产生「买入/卖出/仓位」指令。成本:6 次调用,单日约 ¥0.05,年(250 交易日)约 ¥12-15,比单 prompt(约 ¥0.015/天)约 3 倍但完全可接受。

## 场景:什么时候多角色有价值?

- 你想知道"AI 为什么这么判断、有没有两边都摆"→ 看 `roles`(四角色结论)+ `debate`(多空论据)。
- 你担心"AI 单方向编"→ 多角色逼它把多头/空头都摆出来,主编再收敛。
- 你评估"多角色到底值不值那点成本"→ 换来了可溯源、多视角、幻觉更可控,成本只翻 3 倍。

## 1:1 例子:2026-08-14 四角色各得出什么 + 多空怎么收敛

拿 2026-08-14 那篇预测(就是第 2 章三层全失败那篇)的 `meta.roles` 看,四角色**各执一词**:

- **技术面(tech)**:"A股整体窄幅震荡，创业板领涨但权重股偏弱，市场宽度偏弱，债市超买信号频现，建议谨慎偏多。"
- **资金面(fund)**:"机构前20同向准确率73.3%且连续18天同向，但最新净关注转空，资金面偏谨慎；北向活跃度下降，市场情绪中性偏弱。"
- **情绪面(sentiment)**:"市场情绪偏谨慎，但部分小盘指数情绪分较高，整体中性偏弱。"
- **风控(risk)**:"当前风险指标中性偏弱，量能萎缩且主力资金净流出，但汪汪队入场信号较强，市场或呈震荡格局。"

**研究员多空辩论(meta.debate)**:
- 多头论据:小盘风格活跃、汪汪队信号、部分指数情绪分高。
- 空头论据:主力净流出 202.92 亿、机构净关注转空、中信期货 d5_chg=-6.6%、腾落线 -133737。
- **倾向 lean=down,confidence=0.55**(多头概率略低于空头)。

**结果**:研究员综合四角色论据,把天平压到 down(偏空)——但这恰恰押反了(8-17 实际 +1.41% 普涨)。这说明:**多角色辩论的价值不是"一定对",而是把判断的依据和分歧显式摆出来、可溯源**,让你看到"AI 是基于哪些论据、怎么收敛的"。它也成了第 7 章归因的原始素材(为什么四角色都偏空、实际却大涨,正是要反思的点)。

## 给读者的一句话

**AI 内部是一支 6 人团队:4 个分析师各喂各的数据并行出论据 → 研究员摆多头 vs 空头收敛 → 主编组装+合规把关;好处是可溯源、多视角、压幻觉,代价只是成本翻 3 倍;但不引入交易决策角色(合规红线),只到"关注/风险"层。**
