# 第 10 章 读者能复现的预测流程:手把手跑一次

> 一句话定位:照做就能复刻一套每日预测。

## 白话:什么是「可复现流程」?

前面九章讲的是"系统怎么运作",这一章给你**一份能自己复刻的手册**——从数据怎么来、怎么喂给 AI、怎么判分回填,到怎么验证,每一步给到可执行的位置(脚本/数据文件/命令)。目的:你(读者)能顺着这条链路,自己重跑一遍,看懂"这套预测到底是怎么从数据变出结论的"。**可复现 = 经得起"质疑→反查→复现"**,不是泛泛而谈。

**一句话链路**:

```
采集(收盘数据/signals/指数入 DB) ──► 注入(load_data 聚合 25 项) ──► 生成(6 角色多空辩论→主编组装 meta+text) ──► 落档(daily_brief.json + history) ──► 次日回填(backfill_hits 判三层命中) ──► 自成长(失败归因→reflection 注入)
```

## 场景:什么时候按这份手册复现?

- 你怀疑"AI 说的依据是不是真有那些数据"→ 按链路反查注入面(第 3 章),看某个论据对应的数据源在不在注入 JSON 里。
- 你想自己复刻一套(在别处/别的市场)→ 把链路里的脚本/数据源换成你自己的,照搬判分与透明展示逻辑。
- 你想验证"这 0.6 命中率怎么来的"→ 按本章重跑 backfill_hits,逐条对账(第 9 章)。

## 1:1 例子:用 2026-08-18(周一)产物走一遍完整链路

以今天(2026-08-18 周一,预测 8-19)为样例,把链路每一步落到真实文件:

1. **看今日产物**:`static-site/data/daily_brief.json` — 顶层 `meta`(date=20260818/version=ai-multi/direction/range/confidence)+ `text`(四段)+ `disclaimer` + `generated_at`。meta 断言层是机器可判分的核心。
2. **看历史命中**:`static-site/data/daily_brief_history.json` — 6 条,stats n=5 hit=3 0.6;8-14 那条带 `hit` 字段(三层全失败原始数据)。
3. **看反思库**:`data/daily_brief_reflections.json` — total_samples=1(8-10 规则版反思);8-17 条注入 reflection n=1 dir_fail=1。
4. **看注入面体积**:对 8-14 跑 `load_data('static-site/data','data/sentiment.db','20260814')`,JSON 32,428 字节 ≈2.2 万 token(第 3 章实测)。
5. **看生成脚本入口**:`scripts/gen_daily_brief.py` main 段 = `backfill_hits → write_outputs → notify → upload_to_r2 → staticdata_sync`,是整条链路的执行骨架;触发由 `run_daily_brief.sh`(带交易日判断)+ launchd `com.trade.daily-brief`(每个交易日 17:50)驱动。

**复刻要点(给想自己做的人)**:不需要照抄我的脚本,核心是复刻**四件事**——①结构化 meta 断言层(让预测可机检);②三层双命中判分(严格,不注水);③降级契约(非交易日/数据不全/区间非法四道刹车);④自成长闭环(失败→归因→反思→注入)。数据源换成你自己能拿到的即可。

## 给读者的一句话

**想复刻这套预测,不必照抄脚本,复刻四件事:结构化 meta 断言层(可机检)+ 三层双命中判分(严格不注水)+ 降级契约(四道刹车)+ 自成长闭环(失败→反思→注入);每一步都能顺着 `daily_brief.json → daily_brief_history.json → daily_brief_reflections.json → gen_daily_brief.py` 反查复现。**

## 复现

- **生成脚本**:`scripts/gen_daily_brief.py`(main 段 backfill_hits → write_outputs → notify → upload_to_r2 → staticdata_sync;HISTORY_LIMIT=90 定义于 L1637)
- **触发脚本**:`scripts/run_daily_brief.sh`(带交易日判断)+ launchd `com.trade.daily-brief`(每个交易日 17:50)
- **数据文件**:`static-site/data/daily_brief.json`(今日)/`static-site/data/daily_brief_history.json`(90 天滚动+stats)/`data/daily_brief_reflections.json`(反思库)/`data/sentiment.db`(输入数据源)
- **关键命令**:
  ```bash
  # 复现链路:①看今日 meta ②看历史命中 ③看反思库
  python3 -c "import json; d=json.load(open('static-site/data/daily_brief.json')); print(d['meta']['date'],d['meta']['direction'],d['meta']['range'],'conf',d['meta']['confidence'])"
  python3 -c "import json; d=json.load(open('static-site/data/daily_brief_history.json')); print(d['total'],d['stats'])"
  python3 -c "import json; d=json.load(open('data/daily_brief_reflections.json')); print('samples',d.get('total_samples'))"
  # ②复现注入体积(对 8-14)
  python3 -c "
  import sys,json; sys.path.insert(0,'scripts')
  from gen_daily_brief import load_data,pick_repo,pick_db
  d=load_data(pick_repo()/'static-site'/'data',pick_db(pick_repo()),'20260814')
  print('JSON 字节:',len(json.dumps(d,ensure_ascii=False).encode()))"
  ```
- **数据截止**:2026-08-18(生产版 `version=ai-multi` 多角色)
- **关键口径一句话**:可复现=顺 daily_brief.json→history→reflections→gen_daily_brief.py 反查;复刻核心四件=meta 断言/三层判分/降级契约/自成长闭环。
