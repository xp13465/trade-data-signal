# 第 9 章 两把尺子:全年收益率 vs 峰值回撤

> 一句话定位:只看一个数会误判——「这一年赚多少」和「这一年最多从高点跌多少」是两把不同的尺子,得分开看。

## 白话:收益率和回撤是两回事

同一个策略、同一年,会出现两个看似矛盾的数字:

- **全年最终净收益率** = 净利 / 峰值资金 = "这一年你最终赚/亏了多少"。
- **峰值资金回撤** = 年内峰值 → 谷底的最大单段跌幅 = "这一年你最多从高点回撤了多少"。

它们**量纲不同、含义不同**。同一年可以**先涨到高点、再回落到谷底、收尾在某处**:最终收益率是看"终点 vs 起点/峰值"的资金效率,回撤是看"中间最大那段下坡"的深度。**先涨后跌的年份,收益率可以为负,回撤却可以很大,两者不矛盾。**

## 场景:什么时候要分清这两把尺子?

- 你在回测页面看到"按年表 -9.26%"和某个"回撤 15%"两个数,觉得对不上、以为出 bug。
- 你想评估一个策略"赚多少"(看收益率)还是"有多惨/多大风险"(看回撤)。
- 你想给策略做风险预算,确认能不能扛得住最大回撤。

**一句话:看一年赚多少,看收益率;看一年多惨/多大风险,看回撤。** 两个不可互相替代、不可直接对比。

## 1:1 真实例子:2011 年 -9.26% vs 14.01%

这是本项目一次真实的"用户困惑"案例,来自 `docs/kelly/analysis/kelly-yearly-vs-drawdown-cognitive-gap.md`。用户看到按年表 `-9.26%` 与 hoverpop `15.99%` 冲突,以为同一标的数据出错了。

数据(2011 年,A 模式,etf_main 费率,每日池+topK):

| 指标 | 数值 | 含义 |
|---|---|---|
| 全年最终净收益率 | **-9.26%** | 这一年你最终亏了 9.26%(净利/峰值资金) |
| 峰值资金回撤 | **14.01%** | 这一年你最多从年内高点回撤了 14.01% |

**为什么两个数同时成立?** 2011 年资金曲线是**先涨后跌**(年内先积累到峰值,再回落到谷底)。"涨上去又跌回来"→ 最终收益率 -9.26%(终点比起点差)、最大回撤 14.01%(中间那段下坡最深)。**两个数在同一只标的上同时成立,是设计的表达,不是 bug。**

> 注:用户看到的是 15.99%(中间演进版回撤),本报告用 `kelly_yearly_dd3.js` 最终复算为 14.01%,以 14.01% 为准。核心结论(两把尺子、先涨后跌)不变。

## 给读者的使用方法

1. **看"赚多少"** → 用收益率(净利/峰值资金)。
2. **看"风险/多惨"** → 用峰值回撤(最大单段跌幅)。
3. **评估策略时两个都要看**:收益率高 + 回撤小 = 好;收益率高但回撤巨大 = 可能扛不住(结合第 5 章"20 倍本金可操作"一起判断)。
4. **对不上不是 bug**:先判断两个数是不是"收益率 vs 回撤"这两把尺子,再下结论。

## 诚实标注

- 2011 年数字基于 A 模式 + etf_main 费率 + 每日池+topK 口径;换模式/费率/口径,具体数值会变,但"两把尺子、先涨后跌可同时成立"的结构不变。
- 本报告回撤用 `kelly_yearly_dd3.js` 最终版(14.01%),此前页面显示 15.99% 为演进版本;UI 已加"两把不同的尺子"白话解释。
- 结论基于本项目特定宇宙与 2011-2026 中国样本,可作方法示范,不当普适结论卖。
