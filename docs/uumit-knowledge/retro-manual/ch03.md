# 第 3 章 费率会吃掉多少收益

> 一句话定位:被忽略的收益杀手——回测默认费率=0(毛收益),真买要交一堆钱,先看净收益。

## 白话:回测的"毛收益"和真买差在哪

很多回测软件(包括本项目早期的模拟回测)**默认费率 = 0**,也就是完全不扣任何手续费、滑点,展示的是**毛收益**——信号本身纯 alpha。但真拿钱去买,每一笔都要交:

- **佣金**:券商收,单边。
- **滑点**:市场摩擦,买卖都有的价差,不是券商费。
- **过户费**:沪市 ETF 收,单边(深市 ETF 当前不收)。
- **印花税**:**ETF 免征**(这是 ETF 比股票便宜的关键),股票才有。
- **最低佣金**:单笔佣金有个最低门槛(如 5 元/笔),小额买卖时占比会特别高。

本项目凯利回测用的是 **5 参数费率模型**:佣金万3(0.0003) + 最低佣金 5 元 + 滑点千1(0.001) + 沪市过户费万0.1(0.00001),ETF 无印花税。而早期"模拟回测"是 **2 参数模型**(只有佣金率 + 滑点),默认 = 0 = 毛收益。

## 场景:什么时候要看净收益?

- 你在回测里看到"收益率 X%",想确认它是毛的还是扣过费的。
- 你要小额买卖(比如每笔 1 万以下)——**最低佣金会吃掉一大块**,收益率可能被严重高估。
- 你在 ETF 和股票之间比较策略,想确认 ETF 免印花税的优势有多大。

**碰到回测数字,先问一句:这是毛收益还是净收益?** 默认 0 费率的回测,等于没算你真实要交的钱。

## 1:1 真实例子:最低佣金怎么吃掉小额买卖

以凯利默认费率(佣金万3 + 最低 5 元)为例。关键门槛:**单边佣金 = 成交额 × 0.0003,但最低 5 元兜底**。最低佣金门槛 = 5 ÷ 0.0003 ≈ **16,667 元**——也就是说,单笔成交额在 1.67 万以下时,佣金永远按 5 元收,不吃那万3 的比率。

- **买 1,000 元**:佣金 = max(1000×0.0003, 5) = **5 元**,占比 = 5/1000 = **0.5%**。
- **买 10,000 元**:佣金 = max(10000×0.0003, 5) = **5 元**(仍触发最低佣金),占比 = 5/10000 = **0.05%**。
- **买超过 16,667 元**:才脱离最低佣金,按万3 计,占比趋近 **0.03%**(0.0003)。

**读法**:同样一笔佣金,小额时占 0.5%(是万3 裸费率的十几倍),大额时才压到 0.03%。**最低佣金对小额交易是杀手。** 你以为佣金是万3,实际上 1 万以下每笔都要先扣 5 元,占比高得多。

再算上滑点(千1)和过户费,本项目凯利默认档对 **1 万元单笔往返费率约 0.6%~1%**(最低佣金占比高);换成议价后的"ETF 主流档"(佣金万0.5 + 最低 0.1 元)能降到约 0.2%~0.3%;最激进的"ETF 最便宜档"(万0.1 + 免最低佣金)约 0.12%~0.15%。**费率档位不同,成本能差 5 倍以上**——这就是为什么"回测默认 0 费率"会严重高估真实收益。

## 给读者的行动清单

1. **看回测数字先问毛/净**:默认 0 费率 = 毛收益,换成你的真实费率重算再判断。
2. **小额必算最低佣金**:每笔 1 万以下的单子,最低佣金 5 元占比不低,别拿毛收益当承诺。
3. **ETF 比股票省印花税**:ETF 免征印花税(股票卖方单边万5),同信号买 ETF 成本明显更低。
4. **费率参数是项目现值,读者实际可能不同**——**务必换成你自己的券商费率重算**,不要照抄本册参数。

> 本项目凯利回测已做 6 档费率预设(0%剥离 / ETF默认 / ETF主流 / ETF最便宜 / 股票默认 / 自定义),前端可实时切换看费率影响;模拟回测仍默认 0 费率(毛收益),是待补的展示缺口。
