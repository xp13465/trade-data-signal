## 全篇口径铁律(读任何一章数字前必读)

- **基准 = v1.1.0 推荐最优组合(§5.4)**:AI宏 5+3+1 = **基础5**[n2NovSpecialIndustry / excludeSpecialBear / janMidRating / janMidSpecial / k2c5HkChase] + **核心3**[r7MayReinforced / excludeAuxCross / greedy15] + **1类回测剔除**(债类/波段不入宇宙)= **8键+1类,总数9**。
- **组合口径 = 每日资金池等分 + AI仓位建议 K=1 + G 用 13万 P≤3d「先卖年轻仓」可操作口径**;G 基线 = **+202,508 / 155.78%**(峰持仓≤20倍本金,可操作)。
- **裸 G(峰持仓 162-173 万 / 162-173 倍本金)不是基准**,只在第 2、5 章作「不可操作反例」讲解,均显式标注「非 v1.1.0 基准口径」。
- **任何非基准口径(裸G / 其他K / 其他P档 / 历史 fixed 口径 / v1.0.0 无 K2C5)都显式声明 + 说明为何出现 + 标注口径差异,不作主推结论**。
- **诚实标注适用边界**:每个数字带「口径 + 数据版本」;回测结论基于本项目特定宇宙(`config/universe_rules.yaml`)与 2011-2026 中国 ETF/指数样本,可作方法示范,**不当普适投资结论卖**。真实世界信号触发/执行/市场环境不同,实际结果会偏离回测。

> 版本注:v1.0.0(2026-08-15)是 AI宏 4+3+1(基础4+核心3,7键+1类);v1.1.0(2026-08-15)把 K2C5 并入基础5 定名「基础5」,升级为 8键+1类。源报告中标注 v1.0.0 的(如象限挖掘 §7 补测)在本册统一按 v1.1.0 基准转述(即 K2C5 默认开),个别保留 v1.0.0 标签处会显式说明。

## 诚实声明

本册仅供**学习研究**用途,不构成任何投资建议。所有回测结论都基于本项目特定宇宙(`config/universe_rules.yaml`)与 2011-2026 中国 ETF/指数历史样本、特定费率参数与卖出模式近似,属**方法示范**而非普适规律;实际交易面临滑点/手续费/流动性/市场环境变化/执行纪律等回测未完全覆盖的因素,历史回测不代表未来收益,可能显著偏离。**请勿仅凭本册数字做投资决策。**
