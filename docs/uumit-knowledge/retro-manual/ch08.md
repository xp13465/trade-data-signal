# 第 8 章 降亏键依玩法模式分裂:A/F 有效、G 有害

> 一句话定位:同一个开关,不同卖出模式结果相反——自己的玩法决定哪些过滤开关有用,别盲目抄组合。

## 白话:什么是"模式分裂"?

同一个降亏键(比如 K2C5 剔除港股追涨),在**短持玩法**(A/F 等固定天数/固定持有)下是正贡献(剔了更赚),但在**长持玩法**(G 卖出信号 / I 追关注+追止损)下反而有害(剔了更亏)。同一个开关,结果方向相反——这就叫**依玩法模式分裂**。

为什么会这样?因为不同卖出模式对"哪些信号有价值"的依赖不同。K2C5 剔除的港股追涨信号,在短持下是拖累,但在长持下可能充当"强平缓冲垫"(被先砍掉记 0 利),剔掉它们反而扰动整个持仓路径。

**一句话:最优 toggle 组合依卖出模式分裂,不一套配置打天下**(经验 E24)。这也是本项目第 7 章挖掘最关键的"分叉"发现。

## 场景:什么时候要警惕模式分裂?

- 你在网上/别处抄来一套"降亏组合",想直接套到自己的玩法上。
- 你看到某个"降亏键很有效"的结论,但不确定它适不适合自己的卖出模式。
- 你想给短持和长持分别配过滤开关,而不是全站一套。

**抄组合前先问:这结论是在什么卖出模式下测的?跟我的玩法一样吗?**

## 1:1 真实例子:K2C5 对 9 模式的边际完全分裂

数据来自 `docs/kelly/analysis/kelly-k2c5-mode-yearly-breakdown.md`(数据版本 2026-08-15 19:08 批;基准 = v1.1.0,8键全开,每日池 + K=1 + G 用 13万 P≤3d)。K2C5 剔除(港股追涨/备涨,159 基笔)对 9 个卖出模式的"剔除边际"Δ净利:

| 模式 | 玩法 | all Δ净利 | y1 Δ净利 | 方向 |
|---|---|---|---|---|
| A(固定10天) | 短持 | **+7,384** | +1,012 | 正 |
| B(3%止盈) | 短持 | +6,157 | +132 | 正 |
| C(5%止盈) | 短持 | +6,352 | +1,012 | 正 |
| D(7%止盈) | 短持 | +6,330 | +1,012 | 正 |
| E(持有5天) | 短持 | +6,545 | +298 | 正 |
| F(持有15天) | 短持 | +4,458 | +1,593 | 正 |
| H(卖出+追止损) | 短/中 | +7,840(最高) | -151 | all 正 / y1 微负 |
| **G(卖出信号)** | **长持** | **-2,256** | +1,071 | **all 负** |
| **I(追关注+追止损)** | **长持** | **-1,365** | +1,354 | **all 负** |

**读法**:
- **A-F 短持 + H 全部正贡献**(A all +7,384 最强、F +4,458 最弱、H +7,840 全矩阵最高)。做短持时,剔除港股追涨可提升收益。
- **可操作 G(-2,256)与长持 I(-1,365)负贡献**——剔除港股追涨反而减利。
- **同一个键,两种相反结果**:对 A/F 有效、对 G 有害。这就是"依模式分裂"。

### 为什么 G 会"剔除反而亏"?——路径噪声机制

按年分解可操作 G 的 K2C5 剔除边际(来自 quadrant §7.5):

| 年 | K2C5Δ |
|---|---|
| 2014 | -3,687 |
| 2015 | +1,084 |
| 2016 | -2,138 |
| 2017 | +1,432 |
| 2018 | +1,843 |
| 2025 | -2,424 |
| **合计** | **-2,256** |

正负交织(2015/2017/2018 正,2014/2016/2025 负),合计 -2,256 → **无稳定方向,路径噪声**。机制:可操作 G = P3d 13万,超仓时强平记 0 利(b0 保守);被剔除的港股追涨交易在 P3d 里大多是"刚买入 ≤3 天的年轻仓",被优先砍掉记 0 利——它们实际充当了**强平缓冲垫**。剔除它们后,同样超仓日强平落到其他仓,改变整个仿真路径,反而让可操作 G 净利减少。

**读法**:G 玩法的"剔除边际"是仿真路径噪声(强平缓冲垫被移除),不是 K2C5 该子群自身净利的反号;对 G 而言,**不做象限降亏键,优化应回到卖出规则 / P3d 档位本身**。

### 给短持玩家的结论

如果你主玩 **A/F 短持**,那么:
- **K2C5 仍第一优先**(A all +7,384 / F +4,458,all+y1 双正,样本 159,多年稳定)。
- **K3(主关注×概念)次之**,但要接受牺牲 2024/2025 概念大赚年的风险(高波动)。
- 短持玩法上,K2C5 的边际在所有核心3 子集下都稳定为正(见第 7 章交互穷举),无叠加冲突。

## 给读者的一句话铁律

**自己用什么卖出模式,决定了哪些过滤开关有用。** 短持(A/F)用降亏键受益,长持(G/I)可能反而受害。**别盲目抄一套组合打天下——先对齐自己的玩法,再决定开哪个键。** 这也是第 6 章"样本外验证"在组合层面的延伸:一套组合在短持玩法下验证有效,不代表长持玩法也有效。

## 诚实标注

- **A-F 卖出模式为二阶近似**(固定持有/止盈模式保持记录卖出日/卖出价不变),G/H/I(信号驱动卖出)精确。
- **G 的方向依赖强平口径**:b0(强平记 0 利)=-2,256,但 b1(乐观线性)=+11,755;y1 前向样本 G 反而 +1,998。负贡献主要集中在前样本(2025-08 之前)。
- **I 的负贡献属路径噪声**(方向随核心3子集摆动,±7,000 内),8 键合计 I 仍 +137,708(正)。
- **y1 方向**:A/C/D/E/F/G/I 的 y1 与 all 同号(G y1 +1,071 转正——剔除在近一年对可操作 G 反而增益),H y1 -151 转负;y1 单年样本小(169 笔内),只作参考不作承诺。
- 结论基于本项目特定宇宙与 2011-2026 中国样本,可作方法示范,不当普适结论卖。
