## 三、三档互证教学法统一模板(全篇写作前提,§23.9)

每章每个指标固定三段,缺一不可:
1. **白话**(是什么):一句话说清指标语义,不堆公式
2. **场景**(什么时候用):给一个「什么时候需要看它」的具体场景
3. **1:1 直白举例**(真实日期+真实数字):拿真实日期落到具体数据,必须从源码+数据产物逐位核实;写不出 1:1=对该指标理解不到位,先停下去核实(§23.9⑤ 强制自查手段)

**1:1 数字核实铁律**:成册时每个 1:1 例子的数字必须从「原料索引」的源码锚点(app.js/lab.js/common.js 常量)+ 数据产物(overview.json / signal_kelly_backtest.json / etf_score_list.json / overfit_monitor.json / lab_sim_*_stats.json / daily_metric)逐位核对,禁止臆造、禁止转述丢失口径(§23.9④ / §5.1 数据说话)。本大纲只列「预留位方向」,不核实数字。
