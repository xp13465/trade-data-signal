### 1.2 判定标准(参考 `docs/walk-forward-report.md`)

- **WFE = WF夏普 / 全样本夏普**(>80% 稳健 / 50-80% 可接受 / <50% 过拟合)
- **固定生产参数 WFE**(生产参数逐段测试)反映真实 WFE,不同于网格搜索 WFE(滚动调参)
- **参数稳定性 = 各段调出参数的 CV=std/mean**(越小越稳定)
- **样本<30 笔无统计意义**

### 1.3 WFE 解读需结合信号语义(情况B 教训)

| 信号类型 | 全样本夏普 | WF夏普 | WFE解读 |
|---|---|---|---|
| 综合评分(hands v5) | 正=信号生效 | 正=测试段仍生效 | WFE>0.8=稳健(测试段仍能选出 forward return 正的信号) |
| 过滤层(降低套牢率) | 过滤后 > 未过滤=样本内有效 | WF > 未过滤全样本=测试段仍有效 | WFE>0.8=稳健;WFE<0.5 但 WF < 未过滤全样本=测试段失效(过拟合) |
| 止损类(情况B) | 负=生效正常 | 负=仍生效 | WFE>1=稳健(稳定地止损生效) |

**过滤层过拟合的关键判据**:不仅看 WFE,还要比较 WF夏普与未过滤基线全样本夏普。若 WF夏普 < 未过滤全样本夏普,说明过滤层在测试段不仅没提升反而退化,即样本内拟合的过滤规则在样本外失效。

### 2.4 分析

**固定参数 5/7 稳健,网格搜索 0/7 稳健**:26 参数综合评分在固定生产参数下整体稳健(sh/csi500/cyb/csi_div/sw_801110 WFE>0.8),说明权重和阈值整体设计合理。但只要尝试调参(网格搜索 4 个总阈值),立刻全部过拟合(WFE<0.16,部分负值),反映 26 参数空间过大,样本内调优极易拟合到噪声。

**sz/hs300 固定参数也过拟合**:这两个指数全样本夏普为负(-0.084/-0.089),说明 hands 信号在深成指/沪深300 上 forward return 为负(hands>=3 触发后 10 日反而下跌)。可能原因:
- sz/hs300 大盘指数趋势性强,hands 综合评分(机会+趋势+动量+波动+流动性+回撤)中的"机会分 low_alert 代理"(position_1y 反向 + RSI 反向)在深熊反弹中误触发
- 历史 low_alert 代理(position+RSI)与生产 low_alert(L1-L8 多维加权)有偏差,实际生产 low_alert 质量更高(参考 alert_score.py L686-689 注释"代理指标无法完全代表 L1-L8 多维加权,实际效果应优于回测")

### 2.5 判定:🟡 可接受(整体稳健,但调参即崩)

- **生产参数整体稳健**(5/7 WFE>0.8),实际生产 low_alert 质量优于代理,预计实际 WFE 更高
- **调参空间过大风险**(网格 0/7 稳健),26 参数任何调优尝试都过拟合
- sz/hs300 大盘指数固定参数 WFE<0.5,需在生产环境观察是否真的失效(可能是 low_alert 代理偏差)

### 2.6 收敛建议(只建议不改代码)

1. **固定 6 维度权重 + 8+8 维度权重 + 4 档阈值,不调参**:26 参数任何调优都过拟合,生产应锁定当前值不动
2. **如必须调,只调 opp_low**(low_alert 极端阈值),其余阈值固定:opp_low 是稳定性最低的参数(CV 12%),其余 CV<7%
3. **长期方向:减参 + regime-based**:
   - 8 维 HIGH_WEIGHTS/LOW_WEIGHTS 按"情绪/位置/量价/趋势"4 类合并(每类 2 维平均),权重从 16 减到 8
   - 各维度内部档位阈值(trend 5 档/vol 5 档/liq 3 档/draw 4 档)按 regime(牛/熊/震荡)切换,而非全样本调参
4. **sz/hs300 实盘观察**:若生产 low_alert 上线后仍 WFE<0.5,考虑对大盘指数用不同 opp_low 阈值(如 opp_low=40 而非 35)

### 3.4 分析

**样本内大幅提升但样本外失效**:未过滤全样本夏普 1.226,过滤后全样本夏普 2.299(+87%),样本内提升显著。但 WF夏普仅 0.773(低于未过滤全样本 1.226),说明过滤层在测试段不仅没提升反而退化。这是典型的"针对历史特定案例调参"过拟合特征。

**dist_from_low60_d1a 极不稳定**(CV=146%):各段调出值在 0.015 和 0.25 之间跳动,且 0.25 远离生产值 0.15。这说明 D1a 中档共振补刀的"涨多"阈值是噪声拟合,各段都没有稳定的最优值。

**dist_from_high_th 中等不稳定**(CV=29%):各段调出值在 0.10/0.15/0.20 三档分布,生产值 0.15 居中,但分散度高。

**dev_ma60_d1a 稳定但偏离生产值**(CV=1.8%,mean=1.04 vs 生产 1.05):各段都调出 1.03-1.08,生产值 1.05 在区间内但偏中位。

**C1|D1a 语义解读**:此过滤层是"上证专属"规则,5 阈值针对 sh 大盘趋势性强的特性调出(C1 高波动+距高点远,D1a 中档共振补刀)。但 sh 大盘趋势性会随市场制度变化(2010 前/后,2015 股灾,2020 注册制等),固定 5 阈值在样本外失效正常。

### 3.5 判定:🔴 过拟合

- **固定参数 WFE=0.336**(过拟合),**网格 WFE=0.071**(严重过拟合)
- **WF夏普 0.773 < 未过滤全样本 1.226**(过滤层测试段反向退化)
- **5 阈值中 1 个极不稳定**(dist_from_low60_d1a CV=146%),2 个中等不稳定,2 个稳定
- 样本内夏普提升 +87% 但样本外失效 = 典型"针对历史过拟合"

### 3.6 收敛建议(只建议不改代码)

1. **C1 主体保留,去掉 D1a 共振补刀**:
   - C1(高波动 atr_pct>=2.5% OR 距高点远 dist_from_high>=15%)2 阈值是稳定主体,样本外仍有效
   - D1a(中档共振补刀 atr_pct∈[1.8%,2.5%) AND dist_from_low60>15% AND dev_ma60>1.05)3 阈值中 dist_from_low60_d1a CV=146% 极不稳定,是过拟合元凶
   - 去掉 D1a 后 sh buy_special 从 612 降到 ~612(只去 D1a 补刀的 109 个),保留 C1 主体过滤效果
2. **如必须保留 D1a,改 regime-based**:
   - 大盘趋势性强(sh 250 日年化>15%)时用 dist_from_low60_d1a=0.25(涨多才滤)
   - 震荡市时用 dist_from_low60_d1a=0.15(标准值)
3. **dist_from_high_th 收敛为 0.15**(生产值),不调:0.10/0.20 是边缘,0.15 居中且语义清晰("距高点跌 15%")
4. **长期方向:与 h5 R2 合并为通用规则**:sh C1|D1a 与 h5 R2 都是 buy_special 过滤层,但 h5 R2 通用稳健(见 §四)。建议 sh 也用 h5 R2 通用规则,去掉 sh 专属 5 阈值

## 五、综合结论

### 5.1 3 信号判定汇总

| 信号 | 固定参数 WFE | 网格 WFE | 参数稳定性 | 判定 | 主要风险 |
|---|---|---|---|---|---|

### 5.2 WFE 解读结合信号语义

1. **综合评分 hands v5**:forward return 正夏普 = 信号生效(选出 forward return 正的买点)。固定参数 5/7 稳健说明生产参数整体设计合理;网格搜索 0/7 稳健不是"参数失效",而是"参数空间过大,样本内调优拟合噪声"。sz/hs300 固定参数 WFE<0.5 需结合 low_alert 代理偏差解读(代理指标质量低于生产 L1-L8 多维加权),未必真过拟合。

2. **上证 C1|D1a 过滤层**:过滤层 forward return 正夏普 = 过滤后保留好信号。样本内夏普从 1.23 拉到 2.30(+87%)看似有效,但 WF夏普 0.77 不仅低于过滤后全样本(2.30),也低于未过滤全样本(1.23)。这是过滤层过拟合的关键判据:**测试段过滤后比未过滤还差**,说明过滤层在样本外反向滤掉了好信号。结合 dist_from_low60_d1a CV=146% 极不稳定,判定过拟合确凿。

3. **量价背离 h5 R2 过滤层**:过滤层 forward return 正夏普 = 过滤后保留好信号。固定参数 7/7 WFE>=0.8,且 WF夏普接近或超过未过滤全样本,说明过滤层在样本外仍能小幅提升或持平。这是"通用规则"特征:6 阈值组合不是针对历史特定案例调参,而是反映"高波动+均线偏离+量价背离"的通用顶部信号。

### 5.5 局限性说明

1. **历史 low_alert 代理偏差**:综合评分 hands v5 验证用 position_1y+RSI 代理 low_alert,与生产 L1-L8 多维加权有偏差(alert_score.py L686-689 注释明确)。实际生产 WFE 可能优于报告值,尤其 sz/hs300 的过拟合判定需在生产环境复测
2. **过滤层 forward return 不等于实际交易收益**:过滤层验证用 horizon=10 日 forward return sharpe,未考虑仓位管理/止损/交易成本。实际 trade_sim 收益可能不同
3. **网格搜索空间有限**:综合评分 26 参数只调 4 总阈值(其余 22 参数固定),未覆盖完整参数空间;过滤层 5/6 阈值网格 3^5/3^6 组合,未覆盖所有可能值。完整网格搜索计算量过大(2^26 = 67M),本报告用代表性网格
4. **数据范围**:sh 1990 起,早期市场(1990-2000)流动性差/数据噪声大,可能影响早期窗口 WF 结果。但 32 个窗口足够覆盖多种市场环境
