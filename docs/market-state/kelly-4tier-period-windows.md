## 摘要(先给结论)

- **增益集中在「下降期 + 上升期」两个状态段**、**2022/2025/2026 三年**、**2022-2024 与 2025-2026 两个大阶段**。

## 4. 为什么 2019 R1_all 大亏(牛熊切换底部误剔)—— 1:1 直白举例

2019 年四档坏档 buy_special **7 笔,全部盈利,净 +5,173.6**(明细):
- 2019-01-25 红利ETF工银 +706.8 / 01-28 深证成指 +1,084.6 / 01-28 银行 +273.0 / 01-28 证券保险 +823.4 / 01-28 红利 +1,047.4 / 02-01 银行 +136.6 / 02-15 红利 +1,102.1(熊市·主跌 6 笔 + 下降期 1 笔)
- 背景:2019-01~02 是 2018 熊市结束的反弹启动期,hs300 仍在年线(MA200)下方 → 四档判「熊市·主跌/下降期」,但买的是红利/银行/证券保险等**底部反转主力,全赚**。R1_all 把它们全剔了 → 丢掉 +5,173。
- 同期救回单(MA60 误杀放回)仅 4 笔 +874.5(2019-06/12 银行/环保)。**净效应 = 剔掉盈利单 +5,173 > 救回盈利单 +874 → 基笔净损 ~-4,300,再被 K1 每日池组合效应放大到 -15,815(G/H/I 三信号模式各 -2.9k~-6.3k)。**
- **对比 V4d_all**:只剔「下降期」,2019 那 6 笔熊市·主跌反转单不被剔(MA60 判牛放行),只剔 02-15 红利 1 笔 +1,102 → 2019 段 V4d 反而 +4,340。
- **一句话**:R1_all 的弱点 = 把「熊市·主跌段」也一刀切,而熊市·主跌段恰恰可能藏着牛熊切换底部的反转盈利单(2019 实证)。主报告 §1b 已有铺垫(熊市·主跌 8 键后净 +12,439 别删),本报告给出分周期实锤。

## 5. 诚实标注(口径局限)

1. **G/H/I cap 伪差**:按状态段/年度/大阶段分桶套 cap(13 万 P≤3d / hold 7/15 万)后再求和 ≠ 全周期一次套,桶内 G/H/I 绝对值只宜看方向、不宜跨表比绝对;A-F(无 cap)精确可加总(状态段 A/F 加总与全周期逐位对齐)。
2. **状态段样本量**:n 基线 = 牛市·主升 420 / 上升期 252 / 下降期 185 / 熊市·主跌 302,下降期段样本最少,但 Δ 信号(+37,731)足够强。
3. **~2015 合并行(2011-2015 共 43 笔)样本极少**,-9,055 只能看方向,2015-2018 大阶段主力是 2016-2018。
4. **2025-2026 = 前向/爆炸年段**:2025 全史 99% 牛侧(主报告 3b),坏档近乎缺席,R1 在该段增益 +13,819 主要来自救回 MA60 误杀单(2025-12 军工行情),V4d 该段 0(无下降期 buy_special 可剔)——前向段两方案差异主要由「救回误杀」驱动,非剔除。
5. **数据批次**:全部基于固化副本 2026-08-17 21:58 批;线上每日重生成有 ~1% 漂移。
6. **对用户决策的影响**:A(R1_all)全周期最高但**在牛熊切换底部(2019 型)会误剔反转盈利单**;B(V4d_all)牺牲 +25k 全周期收益换来**切换期抗误剔**(2019-2021 仅 -1,349)。两者不冲突(R1_all 已含全市场下降期);若上线选 A,建议对「熊市·主跌段 buy_special」单独评估是否保留(即 A 的变体 = 四档只剔「下降期+熊市·主跌中 MA60 也判熊的部分」,可另跑验证,本次未测)。
