## 4. 滞后带机制量化(用户猜想的验证)

- **94/94 救回单 100% 落在滞后带**(价<MA60 且价>MA200)。这是必然机制:四档放行(牛侧)= 价>MA200,MA60 熊 = 价<MA60,交集恰为滞后带。**「救误杀」=「滞后带放行」,与用户猜想完全一致。**
- 全史滞后带交易日 **679 天**(2002-2026,年均 ~28 天),按年分布见数据 json。
- 滞后带内 buy_special×A股 = 94 笔,净 +7,883,**51 笔亏损 -12,741 + 43 笔盈利 +20,624**。
- 按年净利:2016 -86 / 2018 -68 / 2019 +875 / 2020 -570 / **2021 +5,801** / 2023 -2,048 / 2024 -239 / **2025 +9,863** / **2026 -5,645**。**牛年滞后带放行净赚、弱年净亏**——滞后带放行的盈亏极性跟随年份,不是稳定的「放真熊」。
- **2026 年(最新)滞后带放行 33 笔 -5,645.4 = 已卖出实亏 19 笔 -5,014.3 + 未卖出浮亏 14 笔 -631.1**。实亏主力 = 2026-03 一带一路ETF(多笔 -290~-680)/农牧渔ETF(-798/-880)/养殖ETF(-737)/深证100(-259)追高单。**这是当前生效的风险,不是历史样本。**

## 5. 诚实标注(样本/表述/退化)

1. **2015 股灾窗口无样本**:2015 全年 buy_special×A股 仅 6 笔,全部在 2015-03-23~04-03(股灾前牛市顶部),2015-06 之后 0 笔 → 股灾段无法用 buy_special 验证,**
   样本不足如实标注,不下「2015 股灾安全」结论**;仅能从滞后敞口(40 交易日)推断 2015-08 急跌段存在放行窗口但无信号触发。
2. **2024 小微盘「漏剔 21 笔 +5,279」是四档滞后的另一面**:这 21 笔全在 **2024-02-21 之后**(小微盘暴跌后的反弹段),买的是大盘防御 ETF(银行/红利/A100/沪深300/家电),MA60 已判牛但四档因年线仍判坏 → **四档把反弹盈利单多剔了**。即 2024 窗口四档不是「漏放真熊」而是「误剔反弹」,方向相反。小微盘暴跌的 1 月底~2 月上旬 buy_special 只有交集单(两套都剔),无差异样本。
3. **主报告 L105 表述修正**:「上升期 62」应为 **69**(69+25=94 自洽;replace 脚本原始输出 621/225 为 9 模式重复计数膨胀,69×9/25×9);「MA60 误杀的全是盈利单」不准确,应为「94 笔救回单**净 +7,883**,状态全在黄金区(上升期 69 + 牛市·主升 25),但含 51 笔亏损(-12,741)与 43 笔盈利(+20,624)」。
4. **R1_all 的净正由对冲构成**:滞后带放行引入 -12,741 亏损(不含其盈利 20,624,净 +7,883)+ 四档新增剔下降期/熊主跌亏损单(全史 -2,304 A股 净,2022 单年 -9,182)+ 全市场(港股/全球)下降期剔(主报告 +40,409 增益的主要来源之一)+ K1 每日池 top-K 重排效应。**替换式全周期 +65,551 是真实的,但机制不是「白捡」——它同时引入滞后带追高风险,弱年(尤其 2026)是净亏的。**
5. **数据批次**:全部基于固化副本 2026-08-17 21:58 批,复现见 §6。

## 6. 结论与建议(一句话)

- **「会不会放真熊」→ 不会放年线级真熊**:5 段极端行情救回单仅 3 笔 -637.8,真熊段(2022/2024)救回 0、滞后敞口 0。**但会放「急跌回调段(滞后带)」的追高亏损单**,2026 年已实亏 -5,014(一带一路/农牧渔等),是真实且当前的风险。
- **是否影响 A/B 推荐**:不改主报告结论——R1_all 全周期 Δ +65,551 仍是数据最优;但建议上线后把「滞后带放行 + 弱年净亏」纳入监控口径(尤其 2026-03 那批已实亏追高单,可验证是否该对「价<MA60 但价>MA200 且排列偏弱」加额外约束,留作后续维度,本次不扩展)。
- 若严格追求「绝不放急跌段追高」,可考虑在四档基础上叠加「MA60 熊」的滞后带硬约束(即只放行「MA60 牛且四档黄金区」)——这是**对 R1_all 的收紧变体,属新方案,需另跑回测验证是否比 R1_all 更优**,本次未测,留待用户拍板方向后补跑。
