# TASKS.md 定期归档 + 完成度校验机制

> 2026-08-11 建立。目标：TASKS.md 因历史已完成小节 + 会话状态超长行堆积而膨胀（曾 429KB），
> 通过「定期归档 + 超长行压缩 + 完成度校验」保持其小而可用，且不丢任何活跃待办/会话状态。

## 两个脚本

### scripts/tasks_archive.py —— 归档 + 压缩（写操作）

```bash
python3 scripts/tasks_archive.py            # 真实执行（归档块 append 到 TASKS-done.md + 重写 TASKS.md）
python3 scripts/tasks_archive.py --dry-run  # 只打印计划，不写文件
```

动作（幂等，跑第二次 = 0 归档 + 0 压缩，输出字节不变）：

1. **剪切归档**到 `docs/archive/TASKS-done.md`：
   - 标题含 ✅/已完成/已上线/全闭环/已归档 的 `##`/`###`/`####` 已完成小节
     （2026-08-19 扩 `###`：老 `### P2-新-X ✅` 等已完成小块也归档，仅归目标明确标注已完成的，
      `### 保留*`/进行中/近期/下轮起点 等非已完成标题 level3 仍保留）
   - `### 会话状态(日期)` / `### 每日总结(日期)` 历史块
   - 待办小节内旧的会话状态块（从首个 `^(\*\*)?YYYY-MM-DD` 行起）
   - `#### ... 已完成` 锚点
2. **压缩超长行**：`## 📍 当前会话状态` 小节内 `**最后更新**`/`**进行中**`/`**前·最后更新**` 超长行
   （>560ch）压缩为摘要（保留最新状态头 + 指向 git 历史的说明标记）。**幂等**：行内已含
   「本行原」压缩标记的行不再重复压缩，保留标记后主控/人工补写的最新状态（如 AI 预测缺口核实）。
3. **待办保护**：
   - `#### 待办` 锚点 + 其下活跃待办必保留（`scripts/feishu_ws_listener.py` 在此锚点后插
     `- [ ] (飞书 ...)` 行，本脚本不破坏该兼容）
   - 归档小节中的 `- [ ]` 行 + `### 保留*` 子节 bullet 自动并入待办小节（`### 保留待办（tasks_archive.py
     自动并入，防归档丢待办）`），去重后插入锚点小节末尾——不丢任何活跃待办
     （2026-08-08 教训：量子科技第4层需求曾因只存 memory 未落 TASKS 而丢失）
4. **去重**：append 前按 内容 hash（sha1 去空白）+ 规范化标题（去 emoji/日期/尾部括号）双重去重。
5. **原子写**：临时文件 + `os.replace`；单块异常不中断整体。

### scripts/tasks_verify.py —— 完成度校验（只读）

```bash
python3 scripts/tasks_verify.py                     # 完整（含功能词 git grep origin/main）
python3 scripts/tasks_verify.py --no-grep           # 快速（只 hash 存在性 + 归档存在性）
```

输出 `docs/archive/tasks-verify-report-<YYYYMMDD>.md`，3 类不同步清单：

- **① 悬空 hash 但功能在 main / 需人工确认**：小节标已上线，但引用 commit hash 不在 origin/main；
  功能词在 main 代码/产物 grep 命中 = 功能已在 main（hash 过期），未命中 = 需人工确认。
- **② 漏标**：标题标 📋/待办（未标完成），但内容含「已上线/已完成」且引用 hash 全在 main。
- **③ 状态超前**：标题含归档声明（已完成归档/已归档/归档到 TASKS-done.md）但 TASKS-done.md 无对应小节。

细节：8-12 位纯数字（日期/代码如 20260805）与日期+字母（20260805b）按非 hash 排除；归档声明用
`已完成归档|已归档|归档 TASKS-done` 匹配（「批量归档汇总」这类描述性标题不算）。

## 归档规则速查

| 小节类型 | 处理 |
|---|---|
| `##/###/####` 标题含 ✅/已完成/已上线/全闭环/已归档 | 归档到 TASKS-done.md |
| `### 会话状态(日期)` / `### 每日总结(日期)` | 归档 |
| `#### 待办` + 其下活跃项 | 保留 |
| `## 📍 当前会话状态` | 保留，压缩块内超长状态行 |
| 待办小节内旧会话状态块 | 归档，其中 `- [ ]` 待办并入锚点小节 |
| `###` 非已完成标题（保留*/进行中/近期/下轮起点/待实施 等） | 保留（不因扩 `###` 误归） |
| 其余（工作约定/R2待办/全站性能待办/交接状态等） | 保留 |

## 约束与安全

- 归档脚本只改 `TASKS.md` / `docs/archive/TASKS-done.md`；不 commit 不 push（主控统一）。
- 不动前端（app.js/lab.js/style.css，其他 agent 并行开发时防撞）。
- 长行处理用 python 逐行（禁止 grep 超长行全文）。
- 首次执行（2026-08-11）：TASKS.md 429,326 B → 186,198 B（43.4%），归档 28 块，
  压缩 7 条超长行，提取并入 22 条活跃待办；TASKS-done.md 无重复 append。
